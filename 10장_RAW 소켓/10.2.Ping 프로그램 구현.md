# 10.2 Ping 프로그램 구현

## ping이란

- 자신의 호스트가 임의의 다른 컴퓨터와 인터넷을 통해 **잘 연결되어 있는지를 확인**하는 명령

## myping.c 프로그램 동작 순서

1. Raw 소켓 개설
2. 목적지 호스트의 IP 주소 설정
3. ICMP 헤더 작성 후 `sendto()`로 **ICMP ECHO 요청 전송**
4. 타임아웃을 설정하기 위해 `alarm()` 호출 후 `recvfrom()`으로 **ICMP ECHO 응답 대기**
5. 응답이 도착하면 **RTT 값을 측정하여 출력**
6. 타임아웃이 발생하면 **"Request time out" 출력**

---

## 1) Raw 소켓 개설

```c
int sockfd = socket(AF_INET, SOCK_RAW, IPPROTO_ICMP);
```

## 2) 목적지 호스트의 IP 주소 설정

```c
struct sockaddr_in peer;
peer.sin_family = AF_INET;
peer.sin_addr.s_addr = inet_addr(argv[1]);
inet_pton(AF_INET, argv[1], &peer.sin_addr.s_addr);
peer.sin_port = 0;   // 포트번호는 지정하지 않음
```

### IP 헤더를 직접 작성하는 경우

- ICMP 헤더는 **항상 직접 구성**해야 함
- IP 헤더는 **커널이 만들 수도, 사용자가 직접 만들 수도** 있음
- 사용자가 직접 작성하려면 Raw 소켓에 **`IP_HDRINCL`(Header Include)** 옵션 지정

```c
int on = 1;
sockfd = socket(AF_INET, SOCK_RAW, IPPROTO_RAW);
if (setsockopt(sockfd, IPPROTO_IP, IP_HDRINCL, &on, sizeof(on)) < 0) {
    printf("error");
    exit(1);
}
```

## 3) ICMP 에코 요청 전송

### ICMP 헤더 구조

| 필드 | 크기(byte) | 설명 |
|------|-----------|------|
| Type | 1 | `8` : Request, `0` : Reply |
| Code | 1 | `0`으로 설정 |
| Checksum | 2 | 프로그래머가 계산 |
| Ident | 2 | ICMP 데이터의 ID, 보통 프로세스 ID 사용 |
| Seq Num | 2 | 임의로 설정 (일련번호) |
| Data | N | ping에서 전송할 데이터 |

### struct icmphdr 구조체

ECHO 요청 및 응답을 위한 ICMP 헤더는 `struct icmphdr` 구조체에 저장된다.

```c
struct icmphdr {
    u_int8_t   type;        // message type
    u_int8_t   code;        // type sub-code
    u_int16_t  checksum;
    union {
        struct {
            u_int16_t  id;
            u_int16_t  sequence;
        } echo;             // echo datagram
        u_int32_t  gateway; // gateway address
        struct {
            u_int16_t  __unused;
            u_int16_t  mtu;
        } frag;             // path mtu discovery
    } un;
};
```

### ICMP ECHO 요청 헤더 구성 예

```c
char sendbuf[1024];
icmp = (struct icmphdr *) sendbuf;
bzero((char *)icmp, sizeof(struct icmphdr));

icmp->code = 0;
icmp->type = ICMP_TYPE;              // ICMP_ECHO = 8
icmp->un.echo.sequence = seqnum++;   // ping 일련번호
icmp->un.echo.id = getpid();         // pid를 id로 설정
icmp->checksum = 0;                  // checksum 계산 전 반드시 초기화
icmp->checksum = in_chksum((unsigned short *)icmp, sizeof(struct icmphdr)); // checksum 계산

len = sizeof(struct icmphdr);        // 8 바이트
sendsize = sendto(rawsock, sendbuf, len, 0,
                  (struct sockaddr *)&sendaddr, sizeof(struct sockaddr));
```

### ping 데이터로 "hello"(5바이트)를 전송하는 경우

```c
strcpy(&sendbuf[8], "hello");
int len = 8 + strlen("hello");       // 8은 ICMP ECHO 요청 헤더의 크기
sendsize = sendto(rawsock, sendbuf, len, 0,
                  (struct sockaddr *)&sendaddr, sizeof(struct sockaddr));
```

## 4) ICMP ECHO 응답 수신

- ICMP는 **연결형 프로토콜이 아니므로**, 임의의 호스트가 보낸 ICMP 데이터그램을 모두 수신함
- `recvfrom()` 함수의 인자로 리턴되는 상대방 소켓 주소 구조체를 통해 **상대의 IP 주소를 확인**해야 함

```c
char recvbuf[1024];
int recvsize, sockfd;
sockfd = socket(AF_INET, SOCK_RAW, IPPROTO_ICMP);
recvsize = recvfrom(sockfd, recvbuf, sizeof(recvbuf), 0, NULL, NULL);
```

## myping.c의 전체적인 구조

- ICMP 요청 패킷 전송 후 **1초간 타이머를 구동**하며, 이 타임아웃을 처리하기 위해 `select()`의 네 번째 인자 `timeout`을 사용
- ICMP 요청 응답이 타임아웃(1초)될 때까지 오지 않으면, 블록 상태의 `select()`가 리턴하고 **ping을 다시 전송**
- **3번 연속** ICMP 응답을 수신하지 못하면 **"Request Timeout …" 메시지 출력**

```c
while (1) {
    send_ping();
    ret = select(rawsock + 1, &readset, NULL, NULL, &tv);  // 타이머 가동
    if (ret == 0) {                  // 타임 아웃
        if (++notrecv == 3) {
            notrecv = 0;
            puts("Request Timeout … ");
        }
        continue;
    }
    recvfrom(rawsock, ...);          // ping 메시지 수신
    notrecv = 0;                     // 수신된 응답에 대한 처리
    prn_rcvping(recvbuf, recvsize);  // 수신된 ping 메시지 출력
    sleep(1);                        // 1초 간격으로 ping을 보내기 위해 sleep
}
```
