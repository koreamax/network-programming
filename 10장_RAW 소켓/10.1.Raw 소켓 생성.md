# 10.1 Raw 소켓 생성

## 10장 개요: Raw 소켓

### 일반적인 소켓 vs Raw 소켓

- **일반적인 소켓**
  - 데이터 전송 시 TCP, UDP, IP 등 필요한 통신 프로토콜을 처리하기 위한 **각종 헤더가 커널에 의해 자동 생성**됨
- **Raw 소켓**
  - **임의의 프로토콜 헤더를 만들어 전송**할 수 있음
  - 단, **IP 헤더는 커널에 의해 자동 생성**됨

### 10장에서 다루는 내용

- Raw 소켓 생성
- Ping 프로그램 구현

---

## Raw 소켓 생성

- `socket()` 호출 시 인자로 **`SOCK_RAW`** 사용
- 데이터그램 송수신 함수:
  - 전송: `sendto()` 또는 `sendmsg()`
  - 수신: `recvfrom()` 또는 `recvmsg()`

```c
s = socket(AF_INET, SOCK_RAW, protocol);
//         └ 주소체계        └ 프로토콜
```

---

## protocol 인자

- IP 데이터그램이 **어떤 프로토콜 데이터를 포함하는지** 구분하는 값
- **IP 헤더의 protocol 필드**에 입력되는 값
- 수신 측에서는 이 protocol 값을 보고 데이터그램을 전달할 **상위 계층을 선택**
- `SOCK_RAW`를 선택하는 경우에는 원하는 프로토콜을 **명시적으로 정해주어야 함**

### protocol 인자에 올 수 있는 값 (in.h 헤더 파일 참조)

| 상수 | 값 |
|------|----|
| `IPPROTO_ICMP` | 1 |
| `IPPROTO_IGMP` | 2 |
| `IPPROTO_TCP` | 6 |
| `IPPROTO_UDP` | 17 |
| `IPPROTO_IPv6` | 41 |
| `IPPROTO_RAW` | 255 |
