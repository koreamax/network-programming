# 7. 시그널 (Signal)

## 1. 시그널이란?

- 프로세스에서 어떤 **이벤트가 발생한 것을 다른 프로세스에게 알리는 도구**
- **소프트웨어 인터럽트**(software interrupt)라고도 부름
- 시그널 이름은 모두 `SIG` 로 시작하며, `<signal.h>` 에 정의되어 있음

---

## 2. 시그널 종류와 발생 조건

| 시그널 | 발생 조건 |
| --- | --- |
| `SIGINT` | (interrupt) 인터럽트키(`CTRL-C`)를 입력했을 때 발생 |
| `SIGKILL` | 강제 종료 시그널. 프로세스가 이 시그널을 **무시하거나 블록할 수 없음** |
| `SIGIO` | 비동기 입출력이 발생했을 때 전달 |
| `SIGPIPE` | 닫힌 파이프나 소켓에 데이터를 쓰거나 읽기를 시도할 때 발생 |
| `SIGCHLD` | 자식 프로세스가 종료되거나 취소될 때 부모 프로세스에게 전달 |
| `SIGPWR` | 전원의 중단 및 재시작 시 `init` 프로세스로 전달 |
| `SIGTSTP` | 키보드에서 중지키(보통 `CTRL-Z`)를 눌렀을 때 발생 |
| `SIGSYS` | 잘못된 시스템 호출 시 발생 |
| `SIGURG` | (urgent) 대역외(out-of-band) 데이터를 수신했을 때 발생 |
| `SIGUSR1`, `SIGUSR2` | 사용자가 임의의 목적으로 사용할 수 있는 시그널 |
| `SIGHUP` | (hang up) 터미널과 연결이 끊겼을 때 세션 리더에게 전달 |
| `SIGQUIT` | 종료키(보통 `CTRL-\`)를 눌렀을 때 전달 |
| `SIGILL` | 프로세스가 규칙에 어긋난 명령을 수행하려고 할 때 전달 |
| `SIGTRAP` | (trap) 프로그램이 디버깅 지점에 도달하면 전달 |
| `SIGABRT` | `abort()` 함수를 호출하면 발생 |
| `SIGFPE` | (floating point error) 숫자를 0으로 나누거나 연산 에러 시 발생 |
| `SIGVTALRM` | `setitimer()` 함수에 의한 가상 타이머 시간 만료를 알림 |

## 3. 시그널 발생 (전송)

| 시스템 콜 | 설명 | 원형 |
| --- | --- | --- |
| `kill()` | **다른 프로세스**에게 시그널을 보냄 | `int kill(pid_t pid, int sig);` |
| `raise()` | **자기 자신**에게 시그널을 보냄 | `int raise(int sig);` |

---

## 4. 시그널 처리 기본 동작

시그널 수신 시 처리할 수 있는 동작은 다음과 같다.

1. **정해진 기본 동작 수행** — 대부분 프로세스 종료
2. **시그널 무시(ignore)** — 시그널을 받지 않은 것처럼 무시
3. **시그널 블록(block)** — 시그널 대기큐에 넣고, 프로세스는 하던 동작을 계속 수행한 뒤 나중에 처리.
   블록시킬 시그널은 **bitmask 형태**로 시그널 블록 마스크에 추가
4. **시그널 핸들러 수행** — 사용자가 지정한 작업 수행

> **무시 vs 블록**
> - 무시: 시그널을 버려서 처리하지 않음
> - 블록: 일단 미뤄 두었다가, 언블록되면 나중에 처리

> `SIGKILL`, `SIGSTOP` 은 핸들러 등록 / 무시 / 블록이 **불가능**하며 항상 기본 동작을 수행한다.

## 5. 시그널 집합 (`sigset_t`)

여러 개의 시그널을 한 번에 표시하기 위해 시그널 집합 타입을 사용하며,
여러 시그널을 **bitmask 형태로 누적**하여 표시할 수 있다.

```c
#include <signal.h>

int sigemptyset(sigset_t *set);                       // 시그널 집합 set을 비운다
int sigfillset(sigset_t *set);                        // set에 모든 시그널을 포함시킨다
int sigaddset(sigset_t *set, int signum);             // set에 signum 시그널을 추가
int sigdelset(sigset_t *set, int signum);             // set에서 signum 시그널을 삭제
int sigismember(const sigset_t *set, int signum);     // set에 signum 시그널이 포함되어 있는지 확인
```

### 예제 1) `signals` 집합에 `SIGINT` 만 남기기

```c
sigset_t signals;
sigemptyset(&signals);         // 시그널 집합을 빈 상태로 만듦
sigaddset(&signals, SIGINT);   // signals 집합에 SIGINT 추가
```

### 예제 2) `SIGINT` 시그널만 제거하기

```c
sigset_t signals;
sigfillset(&signals);          // 모든 시그널을 포함한 fill 상태로 만듦
sigdelset(&signals, SIGINT);   // signals 집합에서 SIGINT 제거
```

### 예제 3) 특정 시그널 포함 여부 확인

```c
sigset_t signals;
sigemptyset(&signals);         // 빈 상태로 만듦
sigaddset(&signals, SIGINT);   // SIGINT 추가

if (sigismember(&signals, SIGINT))
    printf("this is true\n");  // 실행됨

if (sigismember(&signals, SIGPIPE))
    printf("this is false\n"); // 실행 안 됨
```

## 6. 시그널 핸들러 설정 — `sigaction()`

`sigaction()` 함수를 이용해 시그널 수신 시 호출할 함수(시그널 핸들러)를 등록한다.

```c
int sigaction(int signum, const struct sigaction *act, struct sigaction *oldact);
```

- `signum` : 처리할 대상이 되는 시그널
- `act` : `signum` 시그널이 발생했을 때 참조하여 동작을 결정하는 구조체

### `struct sigaction` 구조체

```c
struct sigaction {
    void     (*sa_handler)(int);                          // 시그널 핸들러
    void     (*sa_sigaction)(int, siginfo_t *, void *);   // 부가 정보를 이용할 때 사용하는 핸들러
    sigset_t   sa_mask;                                   // 핸들러 동작 중 블록시킬 시그널 집합
    int        sa_flags;                                  // 동작 옵션
    void     (*sa_restorer)(void);                        // 사용되지 않음
};
```

| 필드 | 설명 |
| --- | --- |
| `sa_handler` | 시그널 핸들러 함수 |
| `sa_sigaction` | 시그널에 대한 부가 정보(`siginfo_t`)를 이용할 때 사용 |
| `sa_mask` | 시그널 핸들러가 동작하는 동안 블록시킬 시그널 집합. 일반적으로 핸들러 수행 중 인터럽트를 받지 않는 것이 안전하므로 `sigfillset(&act.sa_mask)` 로 모든 시그널을 포함시키는 것이 보통 |
| `sa_flags` | 핸들러 동작 방식 옵션 |
| `sa_restorer` | 사용되지 않음 |

### `sa_flags` 값

| 플래그 | 설명 |
| --- | --- |
| `SA_RESTART` | 시그널 핸들러 처리 후, 시그널로 인해 중단됐던 **시스템 콜을 계속 수행** |
| `SA_NOCLDWAIT` | **좀비 프로세스**를 만들지 않도록 하는 플래그. 주로 `SIGCHLD` 처리 시 사용 |
| `SA_NODEFER` | 핸들러 수행 중 여러 시그널이 도착하면, 기본은 하나만 처리하지만 설정 시 **도착한 시그널 수만큼** 핸들러 수행 |
| `SA_SIGINFO` | `sa_sigaction` 에 명시된 핸들러가 호출됨 (미설정 시 `sa_handler` 호출) |
| `SA_ONESHOT` / `SA_RESETHAND` | 핸들러가 실행된 후 기본 동작(`SIG_DFL`)으로 복귀 |

### 핸들러 등록 코드 예시

```c
struct sigaction act;
sigset_t masksets;

sigfillset(&masksets);          // masksets에 모든 시그널 포함
act.sa_handler = catch_sigint;  // 시그널 핸들러 함수 설정
act.sa_mask = masksets;         // 핸들러 실행 중 모든 시그널 블록
act.sa_flags = 0;

sigaction(SIGINT, &act, NULL);
```
