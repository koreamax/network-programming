## 6.3 inetd를 이용한 서버 구축

- 유닉스에서 제공하는 **`inetd` 데몬**을 이용하여 서버 구축
- 리눅스에서는 **`xinetd` 데몬** 제공

### inetd 환경 설정 (시스템 관리자만 변경 가능)

#### 1) `/etc/services` — 인터넷 서비스 등록 파일에 서비스 등록

```
# /etc/services 파일에 추가
myecho_service    5000/tcp
```

> `myecho_service` 서비스를 **TCP 프로토콜 5000번 포트**로 제공한다는 것을 지정

#### 2) `/etc/inetd.conf` — inetd 환경 설정 파일에 서비스 등록

```
# 서비스명         소켓타입  프로토콜  wait/nowait  사용자  실행프로그램 경로
myecho_service    stream    tcp       nowait       root    /root/myecho_service/myecho_service
```

> **`wait` / `nowait`**
> 클라이언트 요청이 들어왔을 때
> - `nowait` : **새로운 프로세스를 생성**하여 처리
> - `wait` : 이전에 서비스 중인 프로세스가 **종료되기를 기다린 후** 요청 처리

### 서비스 등록(반영)

- 설정 변경 후 **`inetd restart`** 명령으로 재시작

| 동작 | 명령문 |
| --- | --- |
| 시작 | `/etc/rc.d/init.d/inet start` |
| 종료 | `/etc/rc.d/init.d/inet stop` |
| 재시작 | `/etc/rc.d/init.d/inet restart` |
| 재로딩 | `/etc/rc.d/init.d/inet reload` |
| 상태 보기 | `/etc/rc.d/init.d/inet status` |

## TCP Wrapper

외부에서 `telnet`, `ftp` 등의 TCP/IP 응용 서비스를 이용하려고 할 때,
**상대방 IP 주소를 보고 서비스 제공 여부를 제한**하는 기능.

```
# TCP Wrapper를 사용하지 않는 경우
ftp   stream   tcp   nowait   root   /usr/sbin/ftpd   ftpd

# TCP Wrapper를 사용하는 경우 (tcpd를 거쳐 실행)
ftp   stream   tcp   nowait   root   /usr/sbin/tcpd   in.ftpd -l -a
```

### 접근 제어 파일: `/etc/hosts.allow`, `/etc/hosts.deny`

```
# /etc/hosts.deny — 특정 IP에서 ftp, telnet 거부
ftp, telnet : 203.211.252.36
```

```
# /etc/hosts.deny — 특정 IP에서 모든 서비스 거부
ALL : 203.211.252.36
```

```
# /etc/hosts.deny — 모든 IP에서 모든 서비스 거부
ALL : ALL
```

```
# /etc/hosts.allow — 해당 서브넷에서는 모든 서비스 허용
ALL : 192.168.10.0/255.255.255.0
```

> 일반적으로 `hosts.deny` 에서 `ALL : ALL` 로 전부 막은 뒤, `hosts.allow` 에서 필요한 대상만 허용하는 방식으로 운영한다.
