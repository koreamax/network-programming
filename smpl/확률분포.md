# 확률 분포

## 📌 주요 확률 분포 종류

| 분포 | 정의 |
|------|------|
| **베르누이 분포 (Bernoulli)** | 가위바위보에서 이기거나 아닐 확률 (1회 시행, 성공/실패) |
| **이항 분포 (Binomial)** | 가위바위보를 **n번 했을 때 k번 이길 확률** |
| **균등 분포 (Uniform)** | 확률밀도가 **일정한 분포** |
| **기하 분포 (Geometric)** | **처음 사건이 발생할 때까지의** 시행 횟수 분포 |
| **지수 분포 (Exponential)** | **처음 사건이 발생할 때까지** 걸린 **시간** 분포 |

> 💡 기하 분포와 지수 분포의 관계: 기하는 **이산형(횟수)**, 지수는 **연속형(시간)** 으로 같은 개념의 다른 표현이다.

---

## 📊 확률 함수의 종류

| 약어 | 정식 명칭 | 적용 | 한국어 |
|------|-----------|------|--------|
| **PMF** | Probability **Mass** Function | discrete (이산형) | 확률질량함수 |
| **pdf** | Probability **Density** Function | continuous (연속형) | 확률밀도함수 |
| **CDF** | Cumulative **Distribution** Function | 둘 다 | 누적분포함수 |

> 📝 일부 자료에서는 CDF를 "PDF (Distribution)"로 표기하기도 하지만, 일반적으로 **PDF는 density**, **CDF는 distribution**을 가리킨다.

### 셋의 관계

- **PMF**: $P(X = x)$ — 이산 확률 변수가 특정 값을 가질 확률
- **pdf**: $f(x)$ — 연속 확률 변수의 밀도 (적분해야 확률이 됨)
- **CDF**: $P(X \leq m)$ — 누적된 확률

---

## 🎲 i) Random Variable 구하기 — `random(n, k)`

### 균등 분포 (이산형)

`n`부터 `k`까지 균등하게 분포하는 정수 확률 변수.

#### PMF
$$P(X = x) = \frac{1}{k - n + 1}$$

#### CDF (누적분포함수)
$$P[X \leq m] = \sum_{x=n}^{m} \frac{1}{k - n + 1} = \frac{m - n + 1}{k - n + 1}$$

#### 역함수 변환 — `ranf()` 사용

$\text{ranf}()$ (0부터 1 사이가 일정하게 분포)를 사용하여:

$$\frac{m - n + 1}{k - n + 1} = \text{ranf}()$$

$$m - n + 1 = \text{ranf}() \cdot (k - n + 1)$$

$$\boxed{m = n - 1 + \text{ranf}() \cdot (k - n + 1)}$$

> 💡 이 공식으로 $[n, k]$ 범위의 균등한 정수 난수를 생성할 수 있다.

---

## 🎯 ii) Geometric Variable 구하기 — `geometric(p)`

### 기하 분포

처음 성공이 나올 때까지의 시행 횟수.

#### PMF
$$P(X = x) = (1 - p)^{x - 1} \cdot p$$

#### CDF (등비수열의 합)
$$P[X \leq m] = \sum_{k=1}^{m} (1 - p)^{k - 1} \cdot p = \frac{p \left( 1 - (1 - p)^m \right)}{1 - (1 - p)}$$

$$= 1 - (1 - p)^m$$

#### 역함수 변환

$$1 - (1 - p)^m = \text{ranf}()$$

$$(1 - p)^m = 1 - \text{ranf}()$$

양변에 $\log_{(1-p)}$ 를 취하면:

$$\boxed{m = \log_{(1-p)}\left( 1 - \text{ranf}() \right)}$$

> 📝 원본 노트의 `m = 1 + log_{(p-1)}(1-ranf)` 부분은 OCR/필기 인식 한계로 보입니다. 정확한 식은 위와 같이 $\log_{(1-p)}$ 를 사용하며, 보통 다음 형태로도 쓴다:
> $$m = \frac{\ln(1 - \text{ranf}())}{\ln(1 - p)}$$

---

## ⏱ iii) Exponential Variable 구하기 — `exponential(λ)`

### 지수 분포

처음 사건이 발생할 때까지 걸리는 시간 (연속형).

#### pdf
$$f(x) = \lambda e^{-\lambda t}$$

#### CDF
$$P[X \leq m] = \int_0^m \lambda e^{-\lambda t} \, dt = 1 - e^{-\lambda m}$$

#### 역함수 변환

$$1 - e^{-\lambda m} = \text{ranf}()$$

$$e^{-\lambda m} = 1 - \text{ranf}()$$

양변에 자연로그를 취하면:

$$-\lambda m = \ln(1 - \text{ranf}())$$

$$\boxed{m = \frac{\ln(1 - \text{ranf}())}{-\lambda}}$$

> 💡 $1 - \text{ranf}()$ 도 $[0, 1)$ 사이의 균등 분포이므로, 단순화하여 $m = -\frac{\ln(\text{ranf}())}{\lambda}$ 로도 자주 쓴다.

---

## 🔄 역함수 변환법 (Inverse Transform Method) 정리

세 분포 모두 **동일한 패턴**을 따른다.

### 4단계 절차

1. **CDF를 구한다**: $F(m) = P[X \leq m]$
2. **CDF를 `ranf()`와 같다고 놓는다**: $F(m) = \text{ranf}()$
3. **$m$에 대해 푼다** (역함수)
4. **$m$에 `ranf()` 값을 대입**해 난수 생성

### 분포별 역함수 공식

| 분포 | $m$ 공식 |
|------|----------|
| Uniform $[n, k]$ | $m = n - 1 + \text{ranf}() \cdot (k - n + 1)$ |
| Geometric($p$) | $m = \dfrac{\ln(1 - \text{ranf}())}{\ln(1 - p)}$ |
| Exponential($\lambda$) | $m = \dfrac{\ln(1 - \text{ranf}())}{-\lambda}$ |

---

## ✅ 핵심 요약

1. 주요 확률 분포는 **베르누이, 이항, 균등, 기하, 지수** 분포이다.
2. **PMF**는 이산형, **pdf**는 연속형, **CDF**는 누적 확률을 나타낸다.
3. **균등 분포**의 난수: $m = n - 1 + \text{ranf}() \cdot (k - n + 1)$
4. **기하 분포**의 난수: $m = \dfrac{\ln(1 - \text{ranf}())}{\ln(1 - p)}$
5. **지수 분포**의 난수: $m = \dfrac{\ln(1 - \text{ranf}())}{-\lambda}$
6. 세 공식 모두 **CDF의 역함수**에 균등 난수 `ranf()`를 대입하는 동일한 패턴이다.
