# 4.3.2 select() 시스템 콜

## 사용 문법

```c
#include <sys/types.h>   /* fd_set data type */
#include <sys/time.h>    /* struct timeval */
#include <unistd.h>      /* function prototype might be here */

int select(int maxfdp1,
           fd_set *readfds,
           fd_set *writefds,
           fd_set *exceptfds,
           struct timeval *tvptr);

// Returns: count of ready descriptors, 0 on timeout, -1 if error
```

### 인자 설명

| 인자 | 설명 |
| --- | --- |
| `maxfdp1` | 검사할 디스크립터의 개수 (**max fd plus 1**, 가장 큰 소켓번호 + 1) |
| `readfds` | **읽기** I/O 변화를 감지할 대상 소켓들을 지정하는 `fd_set` |
| `writefds` | **쓰기** I/O 변화를 감지할 대상 소켓들 |
| `exceptfds` | **예외 발생**을 감지할 대상 소켓들 |
| `tvptr` | `select()` 가 기다리는 **시간** 지정 |

> `readfds`/`writefds`/`exceptfds` 는 읽기·쓰기·예외 발생과 같은 I/O 변화가 발생했을 때
> 이를 감지할 대상이 되는 소켓들을 지정하는 **배열형 구조체(`fd_set`)** 이다.

### `struct timeval` (대기 시간)

```c
struct timeval {
    long tv_sec;    /* seconds */
    long tv_usec;   /* and microseconds */
};
```

| `tvptr` 값 | 동작 |
| --- | --- |
| `tvptr == NULL` | 무한히 대기 (wait forever) |
| `tv_sec == 0 && tv_usec == 0` | 전혀 대기하지 않음 (don't wait at all) |
| `tv_sec != 0 \|\| tv_usec != 0` | 지정한 초·마이크로초만큼 대기 |

## `fd_set` 구조체와 소켓번호의 관계

<img width="811" height="343" alt="image" src="https://github.com/user-attachments/assets/62940cc2-d9e6-4860-b49f-2e623dea2c7e" />


- `fd_set` 은 **가능한 디스크립터마다 1비트씩**(one bit per possible descriptor) 대응시키는 비트 배열
- `readfd` / `writefd` / `exceptfd` 각각에 대해, 해당 소켓번호 위치의 비트가 **1이면 감시 대상**
- 비트 배열은 `0` 부터 `maxfdp1 - 1` 까지 사용
  - 예시 그림: `readfd` 는 `fd0`, `fd3` 비트가 1, `writefd` 는 `fd1`, `fd3` 비트가 1

---

## `fd_set` 조작 매크로

```c
FD_ZERO(fd_set *fdset);          /* fdset의 모든 비트를 지운다 */
FD_SET(int fd, fd_set *fdset);   /* fdset 중 소켓 fd에 해당하는 비트를 1로 한다 */
FD_CLR(int fd, fd_set *fdset);   /* fdset 중 소켓 fd에 해당하는 비트를 0으로 한다 */
FD_ISSET(int fd, fd_set *fdset); /* fdset 중 소켓 fd 비트가 세트되어 있으면 양수 값 리턴 */
```

## `select()` 호출

### fd_set 구조체 구성의 예

```c
fd_set read_fds;

FD_ZERO(&read_fds);              // read_fds의 모든 소켓을 0으로 초기화
FD_SET(s, &read_fds);            // 연결용 소켓을 선택

for (i = 1; i < num_chat; i++)   // 모든 통신용 소켓을 선택
    FD_SET(clisock_list[i], &read_fds);
```

- `read_fds` 를 `select()` 의 두 번째 인자(읽기 변화 감지용 `fd_set`)로 지정하고,
  쓰기·예외 발생용 `fd_set` 은 `NULL` 로 지정하여 호출

```c
select(maxfdp1, &read_fds, NULL, NULL, NULL);
```

### `FD_ISSET` 으로 I/O 변화가 발생한 소켓 확인

```c
if (FD_ISSET(s, &read_fds)) {
    // 연결용 소켓 s에서 입력 발생
    // 채팅 참가 신청 처리
}

// 클라이언트 소켓번호 어레이 client[]를 차례로 검색
for (i = 0; i < num_chat; i++) {
    if (FD_ISSET(clisock_list[i], &read_fds)) {
        // 통신용 소켓 clisock_list[i]에서 채팅 메시지 수신
        // 모든 참가자에게 채팅 메시지 방송
    }
}
```
