# 4.3.4 채팅 클라이언트 프로그램 (`chat_client.c`)

- TCP 소켓을 이용한 채팅 클라이언트 프로그램
- `select()` 시스템 콜을 이용한 **non-block chatting client**

| 기능 | 처리 |
| --- | --- |
| 메시지 입력 | 키보드로부터의 **표준 입력(stdin, fd 0)** |
| 메시지 출력 | 모니터 화면으로의 **표준 출력(stdout)** |
| 프로그램 종료 | 특정 **종료 문자 입력** 시 종료 |

---

## 사용 방법 (`tcp_chatcli.c`)

```bash
$ tcp_chatcli 210.94.213.194 철수
```

### 메시지 앞에 이름 붙여 보내기

클라이언트가 보내는 모든 채팅 메시지 앞부분에 **클라이언트의 이름**을 붙여 전송한다.

```c
char bufall[MAXLINE + NAME_LEN],   // 이름 + 메시지를 저장하기 위한 버퍼
     *bufmsg;                      // bufall에서 메시지 시작 부분을 가리키는 포인터

sprintf(bufall, "[%s] : ", "철수");   // bufall 앞부분에 이름을 저장
namelen = strlen(bufall);
bufmsg  = bufall + namelen;           // 메시지의 시작 부분을 찾음

fgets(bufmsg, MAXLINE, stdin);
send(s, bufall, namelen + strlen(bufmsg), 0);
```

## 메인 루프 — `select()` 로 키보드와 소켓 동시 감시

```c
fd_set read_fds;                /* fd_set struct */

FD_ZERO(&read_fds);             /* initialize the set : all bits off */
maxfdp1 = s + 1;                /* maxfdp1 calculate */

while (1) {
    FD_SET(0, &read_fds);       /* turn on bit for standard input (키보드) */
    FD_SET(s, &read_fds);       /* turn on bit for connected socket descriptor (서버) */

    select(maxfdp1, &read_fds, (fd_set *)0, (fd_set *)0, (struct timeval *)0);

    if (FD_ISSET(s, &read_fds))     /* check receive message from server */
        // 서버로부터 온 메시지를 화면으로 프린트

    if (FD_ISSET(0, &read_fds))     /* check send message to server */
        // 키보드로 쓰여진 메시지를 서버로 전송
}
```

- **소켓 `s`** 에 변화 → 서버가 보낸 채팅 메시지 → 화면 출력
- **표준 입력 `0`** 에 변화 → 사용자가 키보드로 입력 → 서버로 전송
- 두 입력원(키보드, 서버)을 `select()` 로 동시에 감시하므로, 어느 한쪽에서 블록되지 않음
