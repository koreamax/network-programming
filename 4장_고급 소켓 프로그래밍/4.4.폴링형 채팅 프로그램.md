# 4.4 폴링형 채팅 프로그램
 
- **폴링 방식**으로 채팅 서버를 구현
- 소켓을 **넌블록 모드**로 설정하고, 채팅 메시지 수신 여부를 폴링 방식으로 점검
## 처리 방식 비교
 
| 방식 | 설명 |
| --- | --- |
| **폴링(polling)** | 데이터를 기다리지 않고 **왔는지 계속 확인**하는 방식 |
| **넌블록(non-block) 모드** | 데이터가 없어도 **멈추지 않는** 방식 |
| **블록(block) 모드** | 데이터가 없으면 **멈추므로** 프로그램이 아무것도 못 함 |
| **비동기(asynchronous)** | 소켓에 데이터가 도착하면 **OS가 `SIGIO` 시그널로 알려주는** 방식 |
 
---
 
## 4.4.1 `fcntl()`
 
- **file control** 을 의미하며, 소켓을 **넌블록 모드**나 **비동기 모드**로 변경할 수 있음
- 소켓의 **소유자**를 설정하거나 현재 소유자를 얻어옴
### 사용 문법
 
```c
#include <unistd.h>
#include <fcntl.h>
 
int fcntl(int fd, int cmd, long flag);
```
 
| 인자 | 설명 |
| --- | --- |
| `fd` | 모드 변경을 원하는 소켓 디스크립터 |
| `cmd` | 명령 (아래 참고) |
| `flag` | 구체적인 옵션 설정 (아래 참고) |
 
**`cmd` (명령)**
 
| 명령 | 동작 |
| --- | --- |
| `F_SETFL` | 플래그 세트 |
| `F_GETFL` | 플래그 읽기 |
| `F_SETOWN` | 소켓의 소유자를 설정 |
| `F_GETOWN` | 현재 소켓의 소유자를 얻어옴 |
 
**`flag` (옵션)**
 
| 옵션 | 의미 |
| --- | --- |
| `O_NONBLOCK` | 넌블록 모드로 설정 |
| `O_ASYNC` | `SIGIO` 시그널에 의해 구동되는 비동기 모드로 설정 |
 
### 모드 설정 코드
 
**넌블록 모드 설정**
 
```c
int val;
if ((val = fcntl(sock_fd, F_GETFL, 0)) < 0) exit(1);
val |= O_NONBLOCK;
if (fcntl(sock_fd, F_SETFL, val) < 0) exit(1);
```
 
**비동기 모드 설정**
 
```c
int val;
if ((val = fcntl(sock_fd, F_GETFL, 0)) < 0) exit(1);
val |= O_ASYNC;
if (fcntl(sock_fd, F_SETFL, val) < 0) exit(1);
```
 
**소켓 소유자 설정 / 조회**
 
```c
fcntl(fd, F_SETOWN, getpid());  // 소유자를 현재 프로세스로 설정
fcntl(fd, F_GETOWN, &pid);      // 현재 소유자를 알아냄
```

## 4.4.2 폴링형 채팅 서버
 
### 넌블록 모드 동작
 
- 소켓들을 `fcntl()` 로 **넌블록 모드**로 설정한 후, 무한 루프를 돌면서 입출력을 **폴링 방식**으로 처리
### 넌블록 소켓에 `recv()` 호출 시 처리
 
```c
n = recv(s, buf, length, 0);
 
if (n > 0) {
    // 정상적으로 읽은 데이터 처리
}
else if (n == -1 && errno == EWOULDBLOCK) {
    // 에러가 아니므로 다음 작업으로 진행
}
else if (n == -1 && errno != EWOULDBLOCK) {
    // 시스템 콜에서 에러가 발생함 → 에러 처리
}
```
 
> `accept()` 가 리턴한 **통신용 소켓의 디폴트는 블록 모드**이므로, 별도로 넌블록 모드로 변경해야 한다.
 
### 소켓이 넌블록 모드인지 확인하는 함수
 
```c
int is_nonblock(int sockfd) {
    int val;
    val = fcntl(sockfd, F_GETFL, 0);   // 기존의 플래그 값을 얻어온다
    if (val & O_NONBLOCK)              // 넌블록 모드인지 확인
        return 0;
    return -1;
}
```
 
### 넌블록 확인 후, 아니면 넌블록으로 변경
 
```c
addrlen   = sizeof(cliaddr);
accp_sock = accept(s, (struct sockaddr *)&cliaddr, &clilen);
 
if (accp_sock == -1 && errno != EWOULDBLOCK)
    errquit("accept fail");
else if (accp_sock > 0) {
    // 채팅 클라이언트 목록에 추가
    clisock_list[num_chat] = accp_sock;
 
    if (is_nonblock(accp_sock) != 0 && set_nonblock(accp_sock) < 0)
        errquit("set_nonblock fail");
 
    num_chat++;
    send(accp_sock, start, strlen(start), 0);
    printf("%d번째 사용자 추가.\n", num_chat);
}
```
