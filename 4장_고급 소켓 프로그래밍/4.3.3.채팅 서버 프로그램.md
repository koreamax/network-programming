## 메인 루프 — `select()` 와 신규 접속 처리

```c
while (1) {
    FD_ZERO(&read_fds);                      /* initialize the set : all bits off */
    FD_SET(s, &read_fds);                    /* turn on bit for listening socket descriptor */

    for (i = 0; i < num_chat; i++)
        FD_SET(client_s[i], &read_fds);      /* turn on bit for connected socket descriptor */

    maxfdp1 = getmax(s) + 1;                 /* maxfdp1 recalculate */
    select(maxfdp1, &read_fds, (fd_set *)0, (fd_set *)0, (struct timeval *)0);

    if (FD_ISSET(s, &read_fds)) {            /* new client connection */
        accept();
        client_s[num_chat] = client_fd;      /* save descriptor */
        num_chat++;
    }
```

- 매 반복마다 `read_fds` 를 초기화한 뒤, **연결용 소켓 `s`** 와 **접속된 클라이언트 소켓 `client_s[]`** 의 비트를 모두 켬
- `getmax(s) + 1` 로 `maxfdp1` 을 다시 계산 후 `select()` 호출
- 연결용 소켓 `s` 에 변화가 있으면 신규 접속 → `accept()` 한 소켓을 `client_s[]` 에 저장하고 `num_chat` 증가

## 메시지 수신 및 방송

```c
    for (i = 0; i < num_chat; i++) {          /* check all clients for data */
        if (FD_ISSET(client_s[i], &read_fds)) {
            recv(client_s[i], rline, MAXLINE, 0);

            for (j = 0; j < num_chat; j++)    /* send data to all clients */
                send(client_s[j], rline, n, 0);
        }
    }
}
```

- 모든 클라이언트 소켓을 검사하여, 데이터가 도착한 소켓에서 `recv()` 로 메시지 수신
- 수신한 메시지를 **모든 참가자(`client_s[0..num_chat-1]`)에게 `send()` 로 방송**

## 통신용 소켓 구분

- 채팅 서버는 클라이언트와의 통신을 위해 **다수의 통신용 소켓**(`accept()` 가 리턴한 소켓들)을 개설
- 이 다수의 소켓들은 **모두 같은 포트 번호**를 사용
- 따라서 각 클라이언트의 연결을 구분하기 위해, **"클라이언트의 IP 주소와 포트번호"** 를 내부적인 키로 사용
