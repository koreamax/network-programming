# 4.3.1 채팅 서버 프로그램 구조

- **셀렉팅(`select()`)** 을 이용하여 채팅 서버 프로그램을 구현

## 채팅 서버의 기능

- 클라이언트의 **채팅 참가 요청 수락**
- 클라이언트들의 송신 메시지를 다른 클라이언트들에게 **방송(broadcast)**
- `select()` 를 사용하여 소켓을 **비동기 모드**로 설정

---

### 동작 흐름

1. `socket()` — 소켓 생성
2. `bind()` — 소켓에 주소 바인드
3. `select()` — **모든 소켓의 I/O 변화 감지** (이후 반복 진입 지점)
4. **연결용 소켓?** 판단
   - **Y (채팅 참가 신청)** → `accept()` 로 연결 수락 → `client_s[]` 에 새로운 소켓번호 추가
   - **N (채팅 메시지 수신)** → 채팅 메시지 발송(다른 참가자에게 방송)
5. 다시 `select()` 로 돌아가 반복

> I/O 변화가 감지된 소켓이 **연결용(리스닝) 소켓**이면 새 참가자의 접속 요청이므로 `accept()` 처리,
> 그 외의 소켓이면 기존 참가자가 보낸 **채팅 메시지**이므로 방송 처리한다.

## 채팅 서버와 클라이언트의 연결 관계

<img width="829" height="507" alt="image" src="https://github.com/user-attachments/assets/345745d0-c188-4f7f-9e68-6f7c98ed4d73" />


- 채팅 서버 프로그램(`chat_server.c`)은 내부에서 `select()` 로 다수 소켓을 한 번에 감시
- 소켓 구성
  - **`s`** : 연결용(리스닝) 소켓 — 새로운 참가자의 채팅 참가 신청을 받음
  - **`client_s[]`** : 이미 접속한 **채팅 참가자별 소켓 배열**
- 각 채팅 참가자(1~4)는 **TCP/IP** 를 통해 서버와 연결되며,
  새로 접속을 시도하는 클라이언트는 **"채팅 참가 신청중"** 상태로 연결용 소켓 `s` 에 연결됨
- 클라이언트 프로그램은 `chat_client.c`

| 구성 요소 | 역할 |
| --- | --- |
| `chat_server.c` | 채팅 서버 프로그램 |
| `select()` | 모든 소켓의 I/O 변화를 한 번에 감지 |
| 소켓 `s` | 연결용(리스닝) 소켓 — 신규 참가 신청 수락 |
| `client_s[]` | 접속된 참가자별 소켓 배열 |
| `chat_client.c` | 채팅 클라이언트 프로그램 |
