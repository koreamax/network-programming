# 2.3.2 TCP 클라이언트 프로그램

## 📌 개요

`daytime` 서비스를 이용하는 간단한 TCP 클라이언트 프로그램의 구현 절차를 단계별로 살펴본다.

---

## 1️⃣ 소켓 개설

```c
s = socket(PF_INET, SOCK_STREAM, 0);
```

| 인자 | 값 | 의미 |
|------|----|------|
| `domain` | `PF_INET` | IPv4 protocol |
| `type` | `SOCK_STREAM` | TCP (stream socket) |
| `protocol` | `0` | 기본 프로토콜 |

---

## 2️⃣ 소켓 주소 설정

서버에 연결하기 위한 `sockaddr_in` 구조체를 채운다.

```c
server_addr.sin_family = AF_INET;                     /* server's address family */
server_addr.sin_addr.s_addr = inet_addr(argv[1]);     /* address conversion */
server_addr.sin_port = htons(13);                     /* daytime service port number */
```

| 필드 | 설정값 | 설명 |
|------|--------|------|
| `sin_family` | `AF_INET` | IPv4 주소 체계 |
| `sin_addr.s_addr` | `inet_addr(argv[1])` | 명령행 인자로 받은 IP 주소를 binary로 변환 |
| `sin_port` | `htons(13)` | daytime 서비스의 well-known 포트(13)를 network byte order로 변환 |

> 💡 **`htons()`** 를 쓰는 이유: 포트 번호는 16비트이므로 `s`(short) 변환 함수를 사용해 host byte order → network byte order로 변환한다.

---

## 3️⃣ 연결 (`connect()`)

```c
connect(s, (struct sockaddr *)&server_addr, sizeof(server_addr));
```

- 첫 번째 인자: 소켓 디스크립터
- 두 번째 인자: 서버 주소 구조체 (일반 `sockaddr *`로 캐스팅)
- 세 번째 인자: 구조체의 크기

> 🤝 이 호출에서 TCP 3-way handshake가 일어나고 연결이 확립된다.

---

## 🔢 포트번호 배정

소켓에 포트가 배정되는 방식은 두 가지이다.

### A. 시스템에 의한 임의 배정

| 소켓 종류 | 배정 시점 |
|-----------|-----------|
| **TCP socket** | `connect()` 호출이 성공한 후 |
| **UDP socket** | `sendto()`가 성공한 후 |

### B. 프로세스에 의한 특정 번호 배정

- **`bind()` 호출 성공 시** 배정된다.

### `bind()` 호출 시 IP/Port 조합별 결과

`bind()`로 IP 주소와 포트를 지정하는 4가지 조합과 그 결과:

| Process specifies IP address | Process specifies port | Result |
|:---:|:---:|---|
| `wildcard` | `0` | kernel이 IP 주소와 포트를 모두 선택 |
| `wildcard` | `nonzero` | kernel이 IP 주소를 선택, 프로세스가 포트 지정 |
| `local IP address` | `0` | 프로세스가 IP 주소를 지정, kernel이 포트 선택 |
| `local IP address` | `nonzero` | 프로세스가 IP 주소와 포트를 모두 지정 |

> 💡 **`INADDR_ANY`** : IP 주소를 wildcard로 지정할 때 사용하는 매크로. 호스트가 가진 모든 IP 주소에 대해 바인딩한다는 의미.

---

## 🔍 소켓 정보 조회 함수

### `getsockname()` — 자신의 소켓 정보

자신의 호스트에 있는 **로컬 소켓 정보**를 알아내는 함수.

```c
int getsockname(int s, (struct sockaddr *)&addr, &addrlen);
```

### `getpeername()` — 상대방 소켓 정보

TCP로 연결된 **상대방(remote) 소켓 정보**를 얻기 위한 함수.

```c
int getpeername(int s, (struct sockaddr *)&addr, &addrlen);
```

### 두 함수 비교

| 함수 | 조회 대상 | 사용 시점 |
|------|-----------|-----------|
| `getsockname()` | 로컬(자신) 소켓 주소 | kernel이 자동 할당한 로컬 IP/Port를 확인할 때 |
| `getpeername()` | 원격(상대방) 소켓 주소 | 연결된 상대방의 IP/Port를 알아낼 때 |

| 인자 | 설명 |
|------|------|
| `s` | 소켓 디스크립터 |
| `addr` | 결과를 받을 `sockaddr` 구조체 포인터 |
| `addrlen` | 구조체 크기를 담은 변수의 포인터 (값-결과 인자) |

---

## ✅ 핵심 요약

1. TCP 클라이언트는 **`socket() → sockaddr_in 설정 → connect()`** 의 3단계로 서버에 연결한다.
2. 포트 번호는 `htons()`로, IP 주소는 `inet_addr()`로 **network byte order로 변환**해야 한다.
3. 포트 배정은 **시스템 자동 배정**(TCP는 `connect()`, UDP는 `sendto()` 시점)과 **`bind()`를 통한 명시적 배정** 두 가지가 있다.
4. `bind()`에서 IP/Port를 0(wildcard)로 두면 kernel이 자동 선택하며, **`INADDR_ANY`** 는 모든 로컬 IP에 바인딩한다는 의미이다.
5. **`getsockname()`** 은 로컬 소켓 주소, **`getpeername()`** 은 원격 소켓 주소를 조회한다.
