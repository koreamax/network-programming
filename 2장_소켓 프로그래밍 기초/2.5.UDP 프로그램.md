# 2.5 UDP 프로그램

## 📌 개요

소켓을 이용하는 **connectionless server 프로그램** 작성 절차를 다룬다.

> 🎯 **echo service**를 제공하는 connectionless 프로그램 작성을 예제로 한다.

### 클라이언트 측 절차

| 순서 | 시스템 콜 | 역할 |
|:---:|-----------|------|
| 1 | `socket()` | 소켓 생성 |
| 2 | `sendto()` | 데이터(요청) 전송 |
| 3 | `recvfrom()` | 데이터(응답) 수신 |
| 4 | `close()` | 소켓 종료 |

### 서버 측 절차

| 순서 | 시스템 콜 | 역할 |
|:---:|-----------|------|
| 1 | `socket()` | 소켓 생성 |
| 2 | `bind()` | well-known port에 바인딩 |
| 3 | `recvfrom()` | 클라이언트로부터 datagram 수신 (block) |
| 4 | `sendto()` | 처리 결과를 클라이언트에 전송 |

### TCP와의 주요 차이점

| 항목 | TCP | UDP |
|------|-----|-----|
| 연결 설정 | `connect()` / `accept()` 필요 | **연결 설정 없음** |
| 데이터 전송 | `send()` / `recv()` | **`sendto()` / `recvfrom()`** |
| 주소 정보 | 연결 시 한 번 지정 | **매 호출마다 지정** |
| `listen()` | 필요 | 불필요 |

> 💡 UDP는 connectionless이므로 `listen()`, `accept()`, `connect()` 단계가 모두 생략된다.

## 📤 `recvfrom()` / `sendto()` 함수

UDP 프로그램에서 데이터 송수신에 사용하는 함수.

```c
#include <sys/socket.h>

ssize_t recvfrom(int sockfd, void *buff, size_t nbytes, int flags,
                 struct sockaddr *from, socklen_t *addrlen);

ssize_t sendto(int sockfd, const void *buff, size_t nbytes, int flags,
               const struct sockaddr *to, socklen_t addrlen);
// Both return: number of bytes read or written if OK, -1 on error
```

### 인자 설명

| 인자 | 설명 |
|------|------|
| `sockfd` | socket descriptor |
| `buff` | 버퍼 포인터 (read 또는 write 대상) |
| `nbytes` | 송신 또는 수신할 바이트 수 |
| `flags` | I/O 함수에 대한 플래그 (이 장에서는 **`0`** 으로 설정) |
| `from` / `to` | **데이터를 송수신할 상대방의 socket address structure** |
| `addrlen` | socket address structure의 크기 |

### `send()` / `recv()`와의 차이

| 함수 | 인자 차이 | 사용 |
|------|-----------|------|
| `send()` / `recv()` | 주소 정보 **없음** | TCP (연결된 소켓) |
| `sendto()` / `recvfrom()` | 주소 정보 **포함** | UDP (매 호출마다 상대 지정) |

> 💡 UDP에서는 매 송수신마다 상대방의 주소를 명시해야 하므로 `sendto()`/`recvfrom()`은 **주소 구조체와 그 크기를 추가 인자로 받는다**.

### 함수별 역할

| 함수 | 동작 | 주소 인자의 의미 |
|------|------|-----------------|
| `sendto()` | 데이터 전송 | **목적지(to)** 주소 — 어디로 보낼지 |
| `recvfrom()` | 데이터 수신 | **출발지(from)** 주소 — 누가 보냈는지 (출력 인자) |

---

## ✅ 핵심 요약

1. UDP는 connectionless이므로 **`listen()`, `accept()`, `connect()` 단계가 없다**.
2. UDP 클라이언트는 **`socket() → sendto() → recvfrom() → close()`** 순으로 동작한다.
3. UDP 서버는 **`socket() → bind() → recvfrom() → sendto()`** 순으로 동작한다.
4. **`sendto()` / `recvfrom()`** 은 `send()` / `recv()`와 달리 **상대방의 주소 구조체와 크기를 인자로 받는다**.
5. `sendto()`의 주소는 **목적지**, `recvfrom()`의 주소는 **출발지**(누가 보냈는지)를 나타낸다.
