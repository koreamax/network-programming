# 9.2.2~3 뮤텍스 사용 예 & 스레드의 Cleanup 핸들러

## 9.2.2 뮤텍스 사용 예 (mutextest.c)

- 뮤텍스를 이용하여 한 스레드가 `counting` 변수에 접근하는 동안 다른 스레드가 이 변수에 접근하지 못하게 하는 것을 확인하는 예제
- `main()`에서 두 개의 스레드를 생성하고, 스레드 시작 함수에서 뮤텍스를 이용해 **1초 간격으로 `counting` 값 출력**
- 한 스레드가 뮤텍스 잠금을 하고 `counting` 변수를 **증가 및 출력하는 동안**, 다른 스레드는 `counting` 변수에 접근하지 못함

## 9.2.3 스레드의 Cleanup 핸들러

### Cleanup 핸들러란

- 스레드가 종료하기 **직전에 임의의 작업을 처리**하도록 하기 위한 함수
- 대표적인 예: 스레드가 종료되기 전에 **뮤텍스 해제를 반드시 수행**해야 함
  - 잠금 상태에서 스레드가 종료되면 뮤텍스를 해제할 기회를 영원히 놓치게 됨

### 핸들러 등록/해제 함수

```c
// cleanup 핸들러를 등록하는 함수
// 인자 routine으로 지정된 함수가 cleanup 핸들러로 등록되고
// arg는 cleanup 핸들러로 넘겨주는 인자로 사용
void pthread_cleanup_push(void (*routine)(void *), void *arg);

// 등록을 해제하는 함수
// execute가 0이면      → 핸들러를 제거하는 동작만 수행
// execute가 non-zero면 → 핸들러를 한 번 수행한 후에 제거
void pthread_cleanup_pop(int execute);
```

### 예제: 뮤텍스 해제를 cleanup 핸들러에 등록

뮤텍스 잠금 상태에서 스레드가 갑자기 종료되는 경우를 대비하여, 뮤텍스를 해제하는 작업을 cleanup 핸들러에 등록한다.

```c
pthread_cleanup_push(pthread_mutex_unlock, (void *)&mut);
pthread_mutex_lock(&mut);

// 크리티컬 영역 처리

pthread_mutex_unlock(&mut);
pthread_cleanup_pop(0);
```
