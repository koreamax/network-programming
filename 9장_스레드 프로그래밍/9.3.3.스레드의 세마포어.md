# 9.3.3 스레드의 세마포어

## 개요

- 동기화는 공유 데이터의 안전한 이용(동기화 문제 해결) 외에도, **어떤 조건이 만족되는 때를 스레드 사이에 서로 알려주는 통신 기능**을 포함
- 세마포어를 이용하여 이러한 동기화/통신을 구현할 수 있음

---

## 세마포어 함수

### sem_init() — 세마포어 초기화

```c
sem_t *sem;             // 스레드용 세마포어 선언
int sem_init(sem_t *sem, int pshared, unsigned int value);
```

- **sem**: 세마포어 객체
- **pshared**: 세마포어를 다른 프로세스와 공유할지 여부 → **0으로 설정**
  - (리눅스에서는 프로세스 간 공유를 지원하지 않음)
- **value**: 세마포어의 초기값

### sem_wait() / sem_trywait() — 세마포어 획득

```c
int sem_wait(sem_t *sem);
int sem_trywait(sem_t *sem);    // sem_wait()의 넌블록(non-block) 버전
                                // 세마포어 값이 0이면 블록되지 않고
                                // EAGAIN 에러와 함께 즉시 리턴
```

- 공유 데이터에 접근(크리티컬 영역에 진입)하려면 세마포어를 얻어야 함
- 세마포어를 얻을 수 없으면 세마포어 값이 증가되기를 기다려야 함
- 동작:
  - 세마포어 값이 **0이면** → `sem_wait()`가 **블록**됨
  - 세마포어 값이 **1이면** → 블록 상태에서 빠져나와 **크리티컬 영역에 진입**

### sem_post() — 세마포어 반환

```c
int sem_post(sem_t *sem);
```

- 크리티컬 영역을 빠져나올 때 사용
- 세마포어의 값을 **1 증가**시킨 후 나옴

### sem_getvalue() — 현재 세마포어 값 읽기

```c
int sem_getvalue(sem_t *sem, int *sval);
```

- `sval`을 통해 세마포어 `sem`의 현재 값을 리턴

### sem_destroy() — 세마포어 삭제

```c
int sem_destroy(sem_t *sem);
```

- 세마포어 사용을 종료할 때 세마포어 자원을 삭제
