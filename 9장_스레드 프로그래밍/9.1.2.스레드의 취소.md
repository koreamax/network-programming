# 9.1.2 스레드의 취소

## 스레드 취소(Cancellation)란

- 한 스레드에서 다른 스레드의 실행을 종료시키는 것
- 다른 스레드를 종료시키려면 **취소 요청(cancel request)** 을 전송
- 취소 요청을 수신한 스레드는 **수용하거나 무시**할 수 있음

### 취소 요청을 수용하는 경우

- **즉시 취소**: 현재 위치에서 즉시 스레드를 취소
- **지연 취소**: 현재 처리하던 작업을 마치고(특정 지점에 도달한 뒤) 스레드를 취소
- 어떤 방식으로 동작할지는 **취소 요청을 받는 스레드에서 미리 설정**해 두어야 함

---

## Cancellation Point

- 취소 요청을 받았을 때 이를 **즉시 처리할 수 있는 함수**를 실행 중인 지점

### 취소 요청을 받아들이는 방법

- **Cancellation point에서 취소 요청을 받으면 항상 즉시 종료**
- **즉시 취소**: cancellation point가 아니어도 즉시 종료
- **지연 취소**: cancellation point에 도달할 때까지 기다린 후 종료

### 대표적인 cancellation point 함수

```
read(), write(), open(), close(), fcntl(),
sleep(), wait(), waitpid(), pthread_join()
```

- 이들 함수가 수행 중일 때 취소 요청이 도착하면 스레드는 즉시 취소됨

---

## 취소 관련 함수

### pthread_setcancelstate() — 취소 요청 수용 여부 설정

```c
int pthread_setcancelstate(int state, int *oldstate);
```

- **state**
  - `PTHREAD_CANCEL_ENABLE` : 취소 요청을 받아들인다
  - `PTHREAD_CANCEL_DISABLE` : 취소 요청을 무시한다
- **oldstate**: 이전의 취소 상태 값을 저장할 변수
  - `NULL`로 지정하면 이전 상태를 저장하지 않음

### pthread_setcanceltype() — 즉시/지연 취소 방식 설정

```c
int pthread_setcanceltype(int type, int *oldstate);
```

- 취소 요청을 받아들이는 경우, cancellation point까지 연기할지 즉시 종료할지를 설정
- **type**
  - `PTHREAD_CANCEL_ASYNCHRONOUS` : 즉시 취소
  - `PTHREAD_CANCEL_DEFERRED` : cancellation point를 만날 때까지 연기

### pthread_testcancel() — 취소 요청 도착 여부 검사

```c
int pthread_testcancel(void);
```

- 현재 도착한 취소 요청이 있는지 검사하고, 있으면 스레드를 종료시킴
- cancellation point가 없는 코드에 **강제로 cancellation point를 넣어주는 효과**

## 예제

### 1. 취소 요청을 무시하는 예 (thcancel_dis.c)

- 스레드의 취소 환경을 `PTHREAD_CANCEL_DISABLE`(취소 요청 무시)로 설정
- 20,000,000번의 루프를 실행
- 50,000번째마다 `pthread_testcancel()`을 호출하여 취소 요청 도착 여부 확인
- 취소 요청이 도착하더라도 무시하도록 했으므로 **모든 루프가 끝까지 실행됨**

#### cancel_and_join()

취소 요청을 보내고 해당 스레드가 종료하기를 기다리는 작업 수행

```c
void cancel_and_join(pthread_t tid) {
    pthread_cancel(tid);          // 취소 요청을 보냄
    pthread_join(tid, &result);   // 해당 스레드가 종료하기를 기다림
}
```

---

### 2. 취소 요청을 연기하는 예 (thcancel_def.c)

- `PTHREAD_CANCEL_ENABLE`로 `pthread_setcancelstate()`를 호출하여 취소 요청 허용
- `pthread_setcanceltype()`을 `PTHREAD_CANCEL_DEFERRED`로 호출하여 **지연 취소 모드**로 설정

```c
// thcancel_def.c의 스레드 시작 함수
// 나머지 코드는 thcancel_dis.c와 동일
void *thrfunc(void *arg) {
    curthd = pthread_self();

    // 취소 요청을 허용하도록 설정
    pthread_setcancelstate(PTHREAD_CANCEL_ENABLE, NULL);

    // 취소 요청을 cancellation point까지 연기
    pthread_setcanceltype(PTHREAD_CANCEL_DEFERRED, NULL);

    // 50,000번마다 취소 요청이 도착했는지 검사
    for (cnt = 1; cnt < max_loop; cnt++)
        if (cnt % 50000 == 0)
            pthread_testcancel();
}
```

---

### 3. 즉시(비동기) 취소되는 예 (thcancel_async.c)

- 취소 요청을 허용하도록 설정하고, 허용 타입을 **비동기(즉시 취소)** 로 설정

```c
// thcancel_async.c의 스레드 시작 함수
void *thrfunc(void *arg) {
    curthd = pthread_self();

    // 취소 요청을 허용하도록 설정
    pthread_setcancelstate(PTHREAD_CANCEL_ENABLE, NULL);

    // 취소 요청을 즉시 수용
    pthread_setcanceltype(PTHREAD_CANCEL_ASYNCHRONOUS, NULL);

    // 50,000번마다 취소 요청이 도착했는지 검사
    for (cnt = 1; cnt < max_loop; cnt++)
        if (cnt % 50000 == 0)
            pthread_testcancel();
}
```

## 정리: 취소 동작 방식 비교

| 설정 | state | type | 동작 |
|------|-------|------|------|
| 취소 무시 | `PTHREAD_CANCEL_DISABLE` | — | 취소 요청을 받아도 무시, 루프 끝까지 실행 |
| 지연 취소 | `PTHREAD_CANCEL_ENABLE` | `PTHREAD_CANCEL_DEFERRED` | cancellation point에 도달해야 종료 |
| 즉시 취소 | `PTHREAD_CANCEL_ENABLE` | `PTHREAD_CANCEL_ASYNCHRONOUS` | 위치와 무관하게 즉시 종료 |
