# 9.3.1 조건변수 사용 방법

## 조건변수(Condition Variable)란

- 공유 데이터의 **상태에 대한 정보**를 스레드 간에 서로 주고받을 필요가 있을 때 사용

### 예: 생산자-소비자 문제

- **생산자 스레드**: 큐에 메시지를 쓰는 동작
- **소비자 스레드**: 큐에 있는 메시지를 꺼내서 출력
- 스레드 간 공유 데이터는 **큐**
- 소비자 스레드가 연속해서 실행되면, 큐가 비어 있어 메시지를 읽어올 수 없고 **불필요하게 시간만 낭비**하는 경우가 발생할 수 있음

### 조건 알림(Signal)

- 특정 조건이 만족된 것을 조건변수를 통해 다른 스레드에게 알려주는 기능을 **조건 알림(signal)을 보낸다**고 함
- "시그널을 보낸다"고도 표현

---

## 조건변수의 동작

- 조건변수는 **반드시 뮤텍스와 함께 사용**되어야 함

### pthread_cond_wait() — 조건 알림을 기다림

```c
int pthread_cond_wait(pthread_cond_t *cond, pthread_mutex_t *mutex);
```

- 예에서, 소비자가 큐에 메시지가 도착한 사실을 알기 위해 호출하는 함수
- 조건변수 `cond`에 **조건 알림이 발생할 때까지 대기**
- 조건변수는 두 번째 인자인 `mutex`에 의해 제어됨
- 호출 시 내부적으로 다음 동작을 수행:
  1. 뮤텍스 해제
  2. 블록 상태로 진입
  3. 조건 알림을 받음
  4. 깨어나면서 뮤텍스를 다시 얻음

### pthread_cond_timedwait() — 시간 제한 대기

- **지정한 시간 동안만** 블록 상태에서 조건 알림을 대기

### pthread_cond_signal() — 조건 알림 전송

```c
int pthread_cond_signal(pthread_cond_t *cond);
```

- 인자로 지정한 조건변수에 대해 조건 알림을 기다리고 있는 스레드에게 알림을 보내고 **블록 상태에서 깨어나게** 해줌

### pthread_cond_broadcast() — 모든 대기 스레드 깨우기

- 조건 알림을 기다리는 스레드가 **둘 이상일 경우**, 해당 조건변수를 기다리는 **모든 스레드를 깨우기** 위해 사용
- 조건 알림을 받으면 블록 상태에서는 벗어나지만, 공유 데이터를 사용하려면 **해당 뮤텍스를 얻어야 함**

## 조건변수의 생성과 삭제

- 조건변수는 사용하기 전에 **반드시 초기화**해야 함

### 초기화

```c
// 매크로를 이용한 초기화 방법
pthread_cond_t cond = PTHREAD_COND_INITIALIZER;

// 함수를 이용한 초기화 방법
pthread_cond_t cond;              // 조건변수 선언
pthread_cond_init(&cond, NULL);
```

- 첫 번째 인자: 초기화시킬 조건변수
- 두 번째 인자: 조건변수에 대한 속성 (NULL이면 기본 속성으로 초기화)

### 삭제

```c
// 더 이상 사용되지 않는 조건변수를 삭제
pthread_cond_destroy(&cond);
```
