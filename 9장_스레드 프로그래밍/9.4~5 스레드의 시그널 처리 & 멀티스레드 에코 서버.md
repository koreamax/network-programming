# 9.4~5 스레드의 시그널 처리 & 멀티스레드 에코 서버

## 9.4 스레드의 시그널 처리

### 멀티스레드에서의 시그널 문제

- 멀티스레드 프로그램에서 **"프로세스"가 시그널을 받으면**, 여러 스레드 중 어떤 스레드가 시그널을 받을지 **예측할 수 없음**

### 시그널 처리 방법

- 시그널과 관계없는 작업을 하는 스레드는 **모든 시그널을 블록**
- **시그널 처리를 전담할 스레드를 지정**하여, 그 스레드만 프로세스에 전달되는 모든 시그널을 받아 처리

---

### pthread_sigmask() — 시그널 블록 마스크 설정

```c
int pthread_sigmask(int how, const sigset_t *newmask, sigset_t *oldmask);
```

- **how**
  - `SIG_SETMASK` : 시그널 블록 마스크를 `newmask` 값으로 설정
  - `SIG_BLOCK` : 시그널 블록 마스크에 `newmask`를 추가
  - `SIG_UNBLOCK` : 시그널 블록 마스크에서 `newmask`를 제거

### pthread_kill() — 다른 스레드에게 시그널 전송

```c
int pthread_kill(pthread_t thread, int signo);
```

- **thread**: 시그널을 수신할 스레드 ID
- **signo**: 전송할 시그널 번호

## 9.5 멀티스레드 에코 서버 (mth_echoserv.c)

에코 서버를 멀티스레드로 구현한 예제.

### 스레드 구성

- **수신 스레드 `echo_recv()`**
  - 클라이언트로부터 메시지를 수신하여 **메시지 큐에 넣는** 작업 수행
- **송신 스레드 `echo_resp()`**
  - **메시지 큐에서 메시지를 꺼내와** 클라이언트에 응답하는 작업 수행

### 스레드 개수

- 에코 서비스를 처리하기 위해 **송신 스레드 1개** 및 **수신 스레드 5개** 생성
- 임의의 수신 스레드가 랜덤하게 에코 수신 서비스를 수행

### 실행 결과

- 수신 스레드의 ID가 계속 변경됨 → **여러 스레드가 에코 서비스를 처리**함을 확인
