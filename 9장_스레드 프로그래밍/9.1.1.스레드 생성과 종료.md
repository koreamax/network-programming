# 9.1.1 스레드 생성과 종료

## 멀티스레드 프로그래밍

- **멀티태스킹**: 여러 작업을 한 컴퓨터에서 병렬로 처리하기 위한 방법 중 하나
- **멀티스레드 프로그램**: 둘 이상의 스레드를 생성하는 프로그램

### 스레드(Thread)란

- 독립적으로 수행되는 프로그램 코드
- **경량 프로세스(light weight process)** 라고도 함
- "프로세스 내에서 독립적으로 수행되는 제어의 흐름"
- 한 프로세스 내의 여러 스레드들은 서로 **전역(global) 변수를 공유**
  - 공유 대상: 코드, 전역 변수, static 변수, heap
- 스레드 간 데이터 공유가 편리함
  - 멀티프로세스 프로그램과 달리 복잡한 **프로세스 간 통신(IPC)** 없이도 데이터 공유가 쉽게 동작

## pthread_create() — 스레드 생성 함수

```c
int pthread_create(
    pthread_t *thread,                      // 생성된 스레드 ID가 리턴됨
    pthread_attr_t *attr,                    // 스레드 속성을 지정하는 인자
    void *(*start_routine)(void *),          // 스레드 시작 함수(start routine)
    void *arg);                              // start routine 함수의 인자
```

### 반환값

- 성공 시 **0** 리턴, 실패 시 **에러 코드 정수 값** 리턴 (`-1`을 리턴하지 않음)
- 자원 부족(메모리 등)이거나 최대 생성 가능 스레드 수를 초과하면 **EAGAIN** 리턴

### -1을 리턴하지 않는 이유

- 전역 변수 `errno`를 여러 스레드가 공유하기 때문
- 만약 `errno`로 에러를 전달하면, 멀티스레드 환경에서 **어떤 스레드가 현재의 errno 값을 발생시켰는지** 정확히 알기 어려움
- 따라서 에러 코드를 직접 반환값으로 돌려줌

### errno 관련 주의사항

- 시스템 콜들은 `errno`를 사용하므로, 멀티스레드에서 기존 시스템 콜을 호출하면 문제가 발생할 수 있음
- **`-D_REENTRANT`** 옵션을 주어 컴파일하면 각 스레드를 위한 별도의 `errno` 제공 가능

## pthread_exit() — 스레드 스스로 종료 (exit()와 유사)

```c
void pthread_exit(void *retval);
```

- 스레드를 종료하려면:
  1. 임의의 위치에서 `pthread_exit()` 호출, 또는
  2. 스레드 시작 함수에서 `return`

### main() 함수와 스레드 종료

- `main()` 함수도 일종의 스레드
- `main()`에서의 **`return`은 "프로세스를 종료"** 하는 것
  - main에서 return하면 자신이 생성한 모든 자식 스레드도 함께 종료
- `main()`에서 **`pthread_exit()`를 호출**하면 main() 스레드만 종료
  - 자신이 생성한 자식 스레드는 종료되지 않음
  - main()이 생성한 모든 자식 스레드가 종료될 때까지 **"프로세스"는 종료되지 않고 대기**

---

## pthread_join() — 자식 스레드 종료를 기다리는 함수

```c
int pthread_join(pthread_t thrd, void **thread_return);
```

- 인자 `thrd`로 지정된 스레드가 종료/취소될 때까지 대기
  - `thrd`: 종료를 기다릴 스레드 ID
- `thread_return`: 자식 스레드의 종료 상태가 저장됨
  - `NULL`로 지정하면 종료 상태 값을 받지 않겠다는 의미
  - 자식 스레드가 다른 스레드에 의해 취소된 경우 종료 값은 **PTHREAD_CANCELED**

### 사용하는 주된 이유

1. 자식 스레드가 종료되기 전에 부모 스레드가 먼저 종료되지 않도록 하기 위함
   - main 스레드가 자식 스레드보다 먼저 종료되면 자식 스레드들도 함께 종료됨
2. 자식 스레드의 종료 시점을 정확히 파악하거나 종료 상태 값을 얻기 위함

- 유닉스 운영체제에 기반을 둔 일련의 **표준 운영체제 인터페이스**
- POSIX 라이브러리에 포함된 **pthread 라이브러리** 사용

## 컴파일 및 예제

`pthread_create()`와 `pthread_self()`를 이용하여 스레드를 생성하고 생성된 스레드의 ID를 얻는 예제.

### 컴파일 옵션

- **`-lpthread`**: pthread 라이브러리(`libpthread.so`)를 링크하겠다는 의미
- 실행 결과 예시: `Init thread ID = 1024` → 프로세스의 main 스레드 ID가 1024

### 스레드 함수의 실패 원인 검사

- 성공 시 0 리턴, 실패 시 에러 코드 값을 리턴하므로 반환값으로 에러를 검사

```c
int status;  // 에러 발생 시 에러코드 리턴
if ((status = pthread_create(&tid, NULL, &thrfunc, NULL)) != 0) {
    printf("thread create error: %s\n", strerror(status));
    exit(0);
}
```

### -D_REENTRANT 옵션

- 프로그램에서 `#define _REENTRANT`를 선언한 것과 동일한 효과
- `errno`를 전역 변수가 아니라 **각 스레드별 고유 변수**로 사용 가능
- 이 옵션을 주면 `_REENTRANT`가 설정되어 각 스레드가 고유한 `errno`를 갖게 됨
