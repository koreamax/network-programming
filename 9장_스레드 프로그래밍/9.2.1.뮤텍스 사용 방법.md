# 9.2.1 뮤텍스 사용 방법

## 뮤텍스(Mutex)란

- **바이너리 세마포어**와 유사한 기능을 제공하며 더 간편함
- 스레드는 공유 데이터를 사용하기 전(**크리티컬 영역에 들어가기 직전**)에 뮤텍스를 **잠금(lock)** 하고, 크리티컬 영역을 나오면서 **잠금을 해제(unlock)** 함으로써 동기화 문제를 해결
- 뮤텍스 잠금을 한 스레드만 공유 데이터에 접근할 수 있고, 다른 스레드들은 잠금이 해제될 때까지 대기 → **한 번에 하나의 스레드만 크리티컬 영역에 접근**

### 적용 범위

- 뮤텍스의 적용 범위는 **프로세스 내부로만 제한**
- 서로 다른 프로세스에서 생성된 스레드들 사이에는 뮤텍스를 사용할 수 없음

---

## 뮤텍스 사용 절차

```c
pthread_mutex_t mutex;             // (1) 뮤텍스 선언
                                   // (2) 뮤텍스 초기화 작업
pthread_mutex_lock(&mutex);        // (3) 뮤텍스 잠금
                                   // (4) 공유 데이터(크리티컬 영역) 액세스
pthread_mutex_unlock(&mutex);      // (5) 뮤텍스 해제
```

### race.c 동기화 문제 해결 예

```c
pthread_mutex_t lock = PTHREAD_MUTEX_INITIALIZER; // 전역 변수로 선언해야 함

void *thrfunc(void *arg) {
    while (1) {
        pthread_mutex_lock(&lock);     // 뮤텍스 잠금
        prn_data(pthread_self());      // 공유 데이터 액세스
        pthread_mutex_unlock(&lock);   // 뮤텍스 잠금 해제
    }
    return NULL;
}
```

## 뮤텍스 선언 및 초기화

- **`pthread_mutex_t`**: 뮤텍스 변수 타입
  - 여러 스레드가 사용하므로 **전역 변수로 선언**해야 함

### 초기화 방법

```c
// 매크로를 이용한 초기화 (기본 속성만 갖는 뮤텍스를 만들 경우)
pthread_mutex_t mutex = PTHREAD_MUTEX_INITIALIZER;

// 함수를 이용한 초기화 (다양한 속성을 갖는 뮤텍스를 만드는 경우)
// attr 인자에 NULL을 주면 기본 속성이 적용됨
pthread_mutex_init(pthread_mutex_t *mutex, pthread_mutexattr_t *attr);
```

### 속성 지정 (pthread_mutexattr_settype)

```c
pthread_mutex_t mutex;             // 뮤텍스 변수 선언
pthread_mutexattr_t attr;          // 뮤텍스 속성 변수 선언

pthread_mutexattr_settype(&attr, type);  // 뮤텍스 타입을 type에 지정
pthread_mutex_init(&mutex, &attr);       // 속성을 적용하여 초기화
```

- **type** — 뮤텍스 타입을 지정하는 상수
  - `PTHREAD_MUTEX_TIMED_NP` : timed 타입
  - `PTHREAD_MUTEX_RECURSIVE_NP` : recursive 타입
  - `PTHREAD_MUTEX_ERRORCHECK_NP` : error checking 타입

---

## 뮤텍스 타입별 특징

### 기본(Default) 뮤텍스

- 초기화에서 특별한 타입을 지정하지 않은 뮤텍스
- **단 한 번의 잠금만 허용**
- 스레드 A가 잠근 뮤텍스를 스레드 A가 또 잠금 시도하면 **데드락 발생** → 스레드 A는 영원히 블록 상태
  - `pthread_mutex_lock()` 대신 `pthread_mutex_trylock()`을 사용하면 블록되는 대신 **EBUSY 에러** 발생 → 예기치 못한 블록 예방
- 뮤텍스 해제는 다른 스레드에서도 가능

### Timed 타입

- `pthread_mutex_timedlock()`을 사용하면 **지정한 시간 동안만 블록**

### Recursive 타입

- 한 스레드가 **한 번 이상 잠금**을 할 수 있음
- `pthread_mutex_lock()`을 호출한 횟수만큼 `pthread_mutex_unlock()`을 호출해야 잠금 해제됨
- 한 스레드가 잠근 상태에서 다른 스레드가 잠금 해제를 시도하면 에러 발생

### Error Check 타입

- 두 번 잠금 시도하면 즉시 에러 발생 → 프로세스 종료
- 잠겨 있지 않은 뮤텍스에 잠금 해제를 시도하면 에러 발생 → 프로세스 종료

---

## 뮤텍스 삭제

- 더 이상 사용하지 않을 경우 삭제 가능
- 잠금된 상태에서 제거를 시도하면 **EBUSY 에러** 발생
- 삭제 전에 뮤텍스를 해제하면 에러가 발생하지 않음

```c
pthread_mutex_unlock(&mutex);
pthread_mutex_destroy(&mutex);
```

---

## 데드락(Deadlock)

- 예: 두 스레드가 두 뮤텍스를 사용하는 상황에서, 각 스레드가 뮤텍스를 하나씩 잠근 채 **상대방이 잠그고 있는 뮤텍스의 해제를 서로 기다리는 현상**
- 프로그램은 영원히 블록됨

### 회피 방법

- 뮤텍스를 잠그는 데 **일정한 순서를 정해두면** 됨
- 작업 처리 순서를 정하고 그 순서에 따라 뮤텍스를 차례로 얻도록 하면 데드락 발생 확률을 줄일 수 있음
