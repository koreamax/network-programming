# 5.3 멀티캐스트 프로그래밍

## 전송 방식 비교

| 방식 | 설명 |
| --- | --- |
| **멀티캐스트(multicast)** | 송신측에서 하나의 데이터그램을 송신하면, 네트워크 내에서 **복제되어 다수의 호스트로 전송** |
| **방송(broadcast)** | 특정 조건에 해당하는 **대상 전체**에게 데이터그램 전송. 주로 **한 LAN 내에서만** 이루어짐 |

### IP 멀티캐스트

- LAN 내에서뿐 아니라 인터넷으로 연결된 임의의 호스트들 중,
  **특정 멀티캐스트 그룹에 가입된 호스트들**을 대상으로 데이터그램을 동시에 전송

---

## 멀티캐스트 그룹

- 멀티캐스트 데이터그램을 수신하고자 하는 **호스트들의 집합**
- **클래스 D의 IP 주소** (`224.0.0.0` ~ `239.255.255.255`)

### 그룹 관리 흐름

| 주체 | 역할 |
| --- | --- |
| **호스트** | `IGMP` 메시지를 전송하여 자신이 멀티캐스트 그룹에 가입된 사실을 라우터에게 알림 |
| **라우터** | 주변의 멀티캐스트 라우터들에게 이 정보를 알려줌 |
| **멀티캐스트 라우터** | `MRP`(Multicast Routing Protocol)을 이용해, 목적지가 멀티캐스트 그룹 주소인 데이터그램을 그룹에 속한 모든 가입자에게 전달 |

---

## 멀티캐스트 데이터그램 송수신

- 해당 멀티캐스트 그룹 IP 주소와 그룹에서 공통으로 사용하는 포트번호를 지정하여 **UDP 데이터그램**을 전송
- 멀티캐스트 데이터그램의 송수신은 **UDP 소켓에서만** 가능

### 이더넷 멀티캐스트 MAC 주소 (총 48비트)

| 구간 | 값 |
| --- | --- |
| 상위 24비트 | `0x01005e` (멀티캐스트임을 알리기 위해 미리 설정된 값) |
| 하위 24비트 중 첫 비트 | 항상 `0` |
| 하위 23비트 | 멀티캐스트 그룹 IP 주소의 **하위 23비트를 복사**하여 사용 |

> 예: `239.3.3.3` 멀티캐스트 그룹에 가입한 호스트는 MAC 주소가 `0x01005e030303` 인 이더넷 프레임을 모두 수신

### 관련 소켓 옵션

| 옵션 | 의미 |
| --- | --- |
| `IP_ADD_MEMBERSHIP` | 멀티캐스트 그룹에 가입 |
| `IP_DROP_MEMBERSHIP` | 멀티캐스트 그룹에서 탈퇴 |
| `IP_MULTICAST_LOOP` | 멀티캐스트 데이터그램의 loopback 허용 여부 지정 |
| `IP_MULTICAST_TTL` | 멀티캐스트 데이터그램의 TTL 값 지정 |
| `IP_MULTICAST_IF` | 멀티캐스트 데이터그램 전송용 인터페이스 지정 |

## `ip_mreq` 구조체 (그룹 주소)

멀티캐스트 그룹 주소를 나타내는 구조체.

```c
#include <netinet/in.h>

struct ip_mreq {
    struct in_addr imr_multiaddr;  /* 멀티캐스트 그룹 주소 */
    struct in_addr imr_interface;  /* 멀티캐스트 그룹과 연결된 인터페이스 주소 */
};
```

### 구조체를 만드는 예

```c
struct sockaddr_in mcast_group;  /* 멀티캐스트 그룹 주소를 저장할 소켓주소 구조체 */
struct ip_mreq mreq;

// 멀티캐스트 그룹주소 지정
memset(&mcast_group, 0, sizeof(mcast_group));
mcast_group.sin_family      = AF_INET;
mcast_group.sin_port        = htons(atoi(argv[2]));
mcast_group.sin_addr.s_addr = inet_addr(argv[1]);

// ip_mreq 구조체 지정
mreq.imr_multiaddr        = mcast_group.sin_addr;
mreq.imr_interface.s_addr = htonl(INADDR_ANY);
```

## 멀티캐스트 데이터그램 수신

UDP 소켓을 개설하고 멀티캐스트 그룹에 가입한 후 **소켓주소 재사용 옵션(`SO_REUSEADDR`)** 을 지정한다.
(소켓이 여러 멀티캐스트 수신자에게 중복 사용될 수 있으므로 옵션이 필요)

```c
// 수신용 UDP 소켓 개설
recv_s = socket(AF_INET, SOCK_DGRAM, 0);

// 멀티캐스트 그룹에 가입
setsockopt(recv_s, IPPROTO_IP, IP_ADD_MEMBERSHIP, &mreq, sizeof(mreq));

// 소켓주소 재사용 옵션 지정
unsigned int set = 1;
setsockopt(recv_s, SOL_SOCKET, SO_REUSEADDR, &set, sizeof(set));

// 소켓 바인드
bind(recv_s, (struct sockaddr *)&mcast_group, sizeof(mcast_group));
```

- 멀티캐스트 데이터그램을 **어떤 포트에서 받는지** 지정하기 위해, 수신용 소켓과 멀티캐스트 소켓주소 `mcast_group` 의 `bind()` 가 필요
- 한 소켓을 통해 여러 멀티캐스트 그룹에 가입할 수 있으며, 이 경우 각각 **다른 `ip_mreq`** 를 사용해야 함

## 멀티캐스트 데이터그램 송신

UDP 소켓을 개설한 후 멀티캐스트 그룹 주소로 데이터그램을 전송한다.

```c
// 송신용 UDP 소켓 개설
send_s = socket(AF_INET, SOCK_DGRAM, 0);

// 멀티캐스트 메시지 전송
char msg[MAXLINE+1];  // 전송할 메시지
sendto(send_s, msg, strlen(msg), 0, (struct sockaddr *)&mcast_group, sizeof(mcast_group));
```

### loopback 취소

- 송신 호스트가 목적지 멀티캐스트 그룹에 가입되어 있는 경우, 멀티캐스트 데이터그램은 **디폴트로 자신의 호스트로 loopback** 됨
- 자신이 전송하는 데이터그램을 받고 싶지 않으면 loopback 옵션을 취소

```c
int no = 0;
setsockopt(send_s, IPPROTO_IP, IP_MULTICAST_LOOP, &no, sizeof(no));
```

### TTL 지정

- 멀티캐스트 데이터그램의 TTL 값은 **디폴트로 1**
- TTL 값을 16으로 지정하는 코드

```c
int ttl = 16;
setsockopt(send_s, IPPROTO_IP, IP_MULTICAST_TTL, &ttl, sizeof(ttl));
```
