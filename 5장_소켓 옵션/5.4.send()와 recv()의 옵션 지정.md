# 5.4 send()와 recv()의 옵션 지정

- 소켓의 옵션을 변경하면, 그 소켓을 통한 **모든 송수신**이 변경된 옵션의 영향을 받음
- `flag` 인자를 이용하면 **한 번의 데이터 송수신에만** 특정한 옵션을 적용할 수 있음
- `flag` 인자는 **bitmask** 형태의 값을 가지며, 여러 옵션을 **OR(`|`)** 로 동시에 선택 가능

---

## MSG_PEEK

- `recv()` 에서 데이터를 **읽기만 하고 수신 버퍼에서 삭제하지 않도록** 함
- 현재 버퍼에 얼마나 많은 데이터가 있는지를 알기 위해 사용
- 주의: 수신 버퍼에 데이터가 없는 경우 `recv()` 가 **무한히 기다림**
  → `MSG_DONTWAIT` 플래그를 같이 설정하여 `recv()` 가 **바로 리턴**되게 하면 됨

```c
// 소켓 s의 수신 버퍼에 현재 얼마나 많은 데이터가 도착해 있는지 알아내는 코드
s = recv(s, buf, sizeof(buf), MSG_PEEK | MSG_DONTWAIT);
```

---

## MSG_WAITALL

- `recv()` 호출 시, 지정된 크기(`n`)의 데이터를 수신하기 전까지는 **리턴하지 않고 대기**

```c
recv(fd, ptr, n, MSG_WAITALL);
```

---

## MSG_OOB

- 대역외(**OOB: out-of-band**) 데이터를 송신 또는 수신할 때 사용
- 크기는 **1바이트로 제한**됨
- 보통 `CTRL-C` 를 입력했을 때 특정 데이터를 전송하는 데 사용

---

## 플래그 정리

| 플래그 | 동작 |
| --- | --- |
| `MSG_PEEK` | 데이터를 읽되 수신 버퍼에서 삭제하지 않음 |
| `MSG_DONTWAIT` | 블록되지 않고 즉시 리턴 (`MSG_PEEK` 와 함께 자주 사용) |
| `MSG_WAITALL` | 요청한 크기만큼 모두 수신할 때까지 대기 |
| `MSG_OOB` | 대역외(OOB) 데이터 송수신 (1바이트) |
