# 5.1 소켓 옵션 변경

## 소켓 옵션 변경 함수

| 함수 | 역할 |
| --- | --- |
| `getsockopt()` | 소켓에 현재 지정되어 있는 옵션 값 **읽기** |
| `setsockopt()` | 소켓 옵션 **변경** |

### 사용 문법

```c
int getsockopt(int s, int level, int opt, void *optval, int *optlen);
int setsockopt(int s, int level, int opt, const void *optval, int optlen);
```

> `getsockopt()` 의 `optlen` 은 **포인터**(입출력용), `setsockopt()` 의 `optlen` 은 **값**으로 전달한다.

| 인자 | 설명 |
| --- | --- |
| `s` | 옵션 내용을 읽을 / 변경할 **소켓 번호** |
| `level` | **프로토콜 레벨** (아래 참고) |
| `opt` | 변경할 / 읽을 **옵션 지정** |
| `optval` | 지정하려는 / 읽을 **옵션 값을 가리키는 포인터** |
| `optlen` | `*optval` 의 **크기** |

**프로토콜 레벨(`level`)**

| 레벨 | 의미 |
| --- | --- |
| `SOL_SOCKET` | 소켓 레벨 옵션 |
| `IPPROTO_IP` | IP 프로토콜에 관한 옵션 |
| `IPPROTO_TCP` | TCP에 관한 옵션 |

---

## 소켓 옵션 목록


| 레벨 | 옵션 | 의미 |
| --- | --- | --- |
| **SOL_SOCKET** | `SO_BROADCAST` | 방송형(broadcast) 메시지 전송 허용 |
| | `SO_DEBUG` | DEBUG 모드를 선택 |
| | `SO_REUSEADDR` | 주소의 재사용 선택 |
| | `SO_LINGER` | 소켓을 닫을 때 미전송된 데이터가 있어도 지정된 시간만큼 기다렸다가 소켓을 닫음 |
| | `SO_KEEPALIVE` | TCP의 keep-alive 동작 선택 |
| | `SO_OOBINLINE` | OOB 데이터를 일반 데이터처럼 읽음 |
| | `SO_RCVBUF` | 수신 버퍼의 크기 변경 |
| | `SO_SNDBUF` | 송신 버퍼의 크기 변경 |
| **IPPROTO_IP** | `IP_TTL` | Time To Live 변경 |
| | `IP_MULTICAST_TTL` | 멀티캐스트 데이터그램의 TTL 변경 |
| | `IP_ADD_MEMBERSHIP` | 멀티캐스트 그룹에 가입 |
| | `IP_DROP_MEMBERSHIP` | 멀티캐스트 그룹에서 탈퇴 |
| | `IP_MULTICAST_LOOP` | 멀티캐스트 데이터그램의 loopback 허용 여부 |
| | `IP_MULTICAST_IF` | 멀티캐스트 데이터그램 전송용 인터페이스 지정 |
| **IPPROTO_TCP** | `TCP_KEEPALIVE` | Keep-alive 확인 메시지 전송 시간 지정 |
| | `TCP_MAXSEG` | TCP의 MSS(최대 메시지 크기) 지정 |
| | `TCP_NODELAY` | Nagle 알고리즘의 선택 |

## 소켓 옵션 변경의 예

### 1) IP 레벨 TTL 값 출력 후 32로 변경

```c
int ttl, optlen;

getsockopt(s, IPPROTO_IP, IP_TTL, &ttl, &optlen);
printf("TTL = %d\n", ttl);

ttl = 32;
setsockopt(s, IPPROTO_IP, IP_TTL, &ttl, sizeof(ttl));
printf("TTL = %d\n", ttl);
```

### 2) 선택/취소형 옵션 (keep-alive)

> 어떤 상태의 **선택 또는 취소** 둘 중 하나를 택하는 옵션의 경우,
> `optval` 값이 **1이면 선택, 0이면 취소**

```c
int set = 1;
setsockopt(s, SOL_SOCKET, SO_KEEPALIVE, &set, sizeof(set));
```

### 3) 수신 버퍼 크기 변경 (`chg_rcvbuf.c`)

TCP 소켓을 개설하고 디폴트 수신 버퍼의 크기를 확인한 뒤, 임의의 크기(여기서는 1,024)로 변경하는 예제. (`SO_RCVBUF` 옵션 사용)

| 항목 | 내용 |
| --- | --- |
| 파일명 | `chg_rcvbuf.c` |
| 동작 | 소켓 옵션을 사용하여 수신 버퍼의 크기 변경 |
| 컴파일 | `gcc -o chg_rcvbuf chg_rcvbuf.c` |
| 실행 | `chg_rcvbuf` |

**실행 결과**

```
$ chg_rcvbuf
디폴트 수신버퍼 크기 : 87380
1024로 변경한 수신버퍼 크기 : 2048
```

**참고**

- **리눅스** : 버퍼 크기를 `setsockopt()` 에 입력한 값의 **두 배**를 기준으로 설정 (1024 요청 → 2048)
- **솔라리스 7** : 536 바이트의 배수의 근사치로 설정
