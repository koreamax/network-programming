# 8.5 세마포어 (Semaphore) — 8.5.4~5 이용 예제 & 공유 메모리 동기화 처리

## 1. `pen_and_note.c` — 세마포어 이용 예제

연필 1자루, 노트 2권이 있는 상황에서 **4개의 프로세스**가 연필 1자루와 노트 1권을 동시에 사용하는 시뮬레이션.

### 자원 사용 (세마포어 감소)
```c
#define PEN   0
#define NOTE  1

semop(semid, &decrease[PEN], 1);   // 연필 사용을 위해 세마포어 1 감소
```
- 위 문장이 성공하면 `PEN` 사용 가능
- 그동안 다른 프로세스들은 `PEN`을 사용하지 못함 (대기)

### 자원 반납 (세마포어 증가)
```c
semop(semid, &increase[PEN], 1);   // 연필 반납
```

### 실행 결과에서 얻는 포인트
- 한 프로세스가 연필·노트를 사용하면 다른 프로세스는 **대기**
- **세마포어 값 = 사용할 수 있는 공유 데이터의 수** 를 나타냄
  → 공유 데이터를 이용할 수 있는 **프로세스의 수가 아님** (주의)
- `printf()`는 **줄 단위로 출력** → 문자를 바로 출력하려면 `setvbuf()` 호출

> 즉, 연필이 1자루뿐이면 세마포어(PEN) 값은 1이고, 동시에 연필을 쥘 수 있는 프로세스는 1개뿐이다. 노트는 2권이므로 NOTE 세마포어 값은 2.

## 2. `shmcontrol.c` — 공유 메모리 동기화 문제 해결

앞서 동기화 문제가 있었던 `shmbusyaccess.c`를 **세마포어로 해결한** 프로그램.

### 핵심 변경
- 공유 메모리에 접근하는 함수 `access_shm()`을 **크리티컬 영역으로 보호**
- 두 프로세스가 `access_shm()`을 **동시에 호출하지 못하게** 함
- 변경된 부분은 `access_shm()` 호출 **전후에 `semop()`을 호출**하여 세마포어를 사용하는 것뿐

### 구조 (개념)
```c
semop(semid, &decrease, 1);   // 진입: 세마포어 감소 (잠금)
access_shm();                 // 크리티컬 영역 (한 번에 한 프로세스만)
semop(semid, &increase, 1);   // 진출: 세마포어 증가 (해제)
```

→ 이진 세마포어로 상호 배제(mutual exclusion)를 구현하여, `shmbusyaccess.c`에서 발생하던 PID 불일치(끼어듦) 문제를 제거한다.

---

## 정리

- `pen_and_note.c`: 자원 사용 전 `semop` 감소, 사용 후 증가 — 자원 수만큼 동시 사용 허용
- 세마포어 값 = **사용 가능한 공유 데이터 수** (프로세스 수가 아님)
- `printf`는 줄 단위 버퍼링 → 즉시 출력은 `setvbuf`
- `shmcontrol.c`: `access_shm()`을 `semop` 감소/증가로 감싸 크리티컬 영역으로 보호 → 동시 접근 차단
- 동기화 문제의 해결책 = **한 번에 한 프로세스만 접근**하도록 세마포어로 상호 배제
