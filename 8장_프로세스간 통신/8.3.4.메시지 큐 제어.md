# 8.3 메시지 큐 (Message Queue) — 8.3.4 메시지 큐 제어

## 1. `msgctl()` — 메시지 큐 제어

메시지 큐에 관한 **정보 읽기**, **동작 허가 권한 변경**, **메시지 큐 삭제** 등을 수행하는 제어 함수.

```c
int msgctl(int msqid, int cmd, struct msgid_ds *buf);
```

| 인자 | 설명 |
|------|------|
| `msqid` | 메시지 큐 객체의 ID |
| `cmd` | 제어 명령 |
| `buf` | `IPC_SET`의 경우 변경시킬 값 / `IPC_STAT`의 경우 객체가 복사될 공간 |

---

## 2. 제어 명령 (cmd)

| 명령 | 동작 |
|------|------|
| `IPC_STAT` | 메시지 큐 객체에 대한 **정보를 얻어옴** (`buf` 인자에 메시지 큐 객체가 복사됨) |
| `IPC_SET` | **r/w 권한, euid, egid, `msg_qbytes`(메시지 큐 최대 크기)** 를 변경 |
| `IPC_RMID` | 메시지 큐를 **삭제**. 읽지 않은 메시지가 있더라도 **즉시 삭제** |

---

## 3. `qctl.c` — 예제

`msgctl()`을 사용하는 예제 프로그램.

- `IPC_STAT` 명령으로 메시지 큐 객체를 얻어와 **큐에 대한 정보 출력**
- `IPC_RMID` 명령으로 **큐 삭제**

### 실행 흐름
1. `mkq.c`로 `key = 1234`인 메시지 큐 생성
2. `qctl.c`로 객체 정보 출력
3. 메시지 큐 삭제

---

## 정리

- 메시지 큐 제어 함수는 `msgctl(msqid, cmd, buf)`
- `IPC_STAT` = 정보 조회(buf로 객체 복사)
- `IPC_SET` = 권한·소유자·최대 크기(`msg_qbytes`) 변경
- `IPC_RMID` = 큐 삭제 (읽지 않은 메시지가 있어도 즉시 삭제)
