# 8.3 메시지 큐 (Message Queue) — 8.3.3 메시지 송수신

## 공통: 메시지 버퍼 구조

```c
struct msgbuf {
    long mtype;       // 메시지 타입 ( > 0 )
    char mtext[1];    // 메시지 데이터
};
```

---

## 1. `msgsnd()` — 메시지 보내기

메시지 큐에 메시지를 넣는 함수.

```c
int msgsnd(int msqid, struct msgbuf *msgp, size_t msgsz, int msgflg);
```

| 인자 | 설명 |
|------|------|
| `msqid` | 메시지 큐 객체의 ID |
| `msgp` | 보낼 메시지 버퍼(`struct msgbuf`) 포인터 |
| `msgsz` | **메시지 데이터의 길이** |
| `msgflg` | 동작 옵션 |

### msgsz 주의점
- `mtype`의 길이(4바이트)는 **제외**
- **`mtext`의 크기만** 나타냄

### msgflg 옵션
| 값 | 동작 |
|----|------|
| `0` | 메시지 큐 공간이 부족하면 **블록(대기)** |
| `IPC_NOWAIT` | 공간이 부족하면 블록되지 않고 `EAGAIN` 에러와 함께 **-1 반환** |

---

## 2. `msgrcv()` — 메시지 받기

메시지 큐로부터 메시지를 읽는 함수.

```c
ssize_t msgrcv(int msqid, struct msgbuf *msgp, size_t msgsz, long msgtype, int msgflg);
```

| 인자 | 설명 |
|------|------|
| `msqid` | 메시지 큐 객체의 ID |
| `msgp` | 읽은 메시지를 저장할 **수신 공간** 포인터 |
| `msgsz` | 수신 공간의 크기 |
| `msgtype` | 읽을 메시지의 **타입 지정** |
| `msgflg` | 동작 옵션 |

### msgtype 값에 따른 동작
| `msgtype` | 동작 |
|-----------|------|
| **양수** | 해당 타입의 메시지 읽음 |
| **0** | 메시지 큐에 **입력된 순서대로** 읽음 |
| **음수** (예: -10) | 타입이 **그 절댓값 이하**인 메시지 읽음 (예: 10 이하) |

### msgflg 옵션
| 값 | 동작 |
|----|------|
| `0` | 조건에 맞는 메시지가 없으면 **대기** |
| `IPC_NOWAIT` | 메시지가 없으면 `EAGAIN` 에러와 함께 **-1 반환** |
| `MSG_NOERROR` | `msgsz` 크기만큼만 읽음 (잘라냄) |

> `MSG_NOERROR`를 설정하지 않으면, 읽은 메시지가 수신 공간 크기보다 클 때 `E2BIG` 에러 발생

---

## 3. `qsnd_pid.c` — 특정 프로세스(PID) 지정 송수신

- `msgtype` 값을 **특정 프로세스의 PID**로 지정 → 지정된 프로세스가 메시지 수신
- `msgtype = getppid()`
  - 자식 프로세스가 부모 프로세스의 PID를 알아낸 후,
    키보드에서 입력된 메시지를 부모 프로세스에게 전송
- 부모 프로세스는 메시지를 수신한 뒤 `msgctl(msqid, IPC_RMID, 0)`으로 메시지 큐 삭제

### `msgctl()`
메시지 큐의 **삭제 등 제어**를 수행하는 함수. (`IPC_RMID` = 큐 제거)

---

## 정리

- 송신: `msgsnd(msqid, msgp, msgsz, msgflg)` — `msgsz`는 `mtext`의 크기만 (mtype 4바이트 제외)
- 수신: `msgrcv(msqid, msgp, msgsz, msgtype, msgflg)`
- `msgtype`: 양수 = 해당 타입 / 0 = 입력 순서 / 음수 = 절댓값 이하 타입
- `IPC_NOWAIT` = 논블로킹(-1, EAGAIN), `MSG_NOERROR` = 초과분 잘라서 읽기(미설정 시 E2BIG)
- 타입에 PID를 사용하면 특정 프로세스 대상 전송 가능
- 큐 삭제/제어는 `msgctl(..., IPC_RMID, ...)`
