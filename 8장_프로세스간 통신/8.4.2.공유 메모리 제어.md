# 8.4 공유 메모리 (Shared Memory) — 8.4.2 공유 메모리 제어

## 1. `shmctl()` — 공유 메모리 제어

공유 메모리에 관한 **정보 읽기**, **동작 허가 권한 변경**, **삭제** 등을 수행하는 제어 함수.

```c
int shmctl(int shmid, int cmd, struct shmid_ds *buf);
```

| 인자 | 설명 |
|------|------|
| `shmid` | 공유 메모리 객체 ID |
| `cmd` | 수행할 명령 |
| `buf` | `cmd`에 따라 의미가 달라짐 — `IPC_STAT`: 얻어온 객체 저장, `IPC_SET`: 변경할 내용 저장 |

### 제어 명령 (cmd)
| 명령 | 동작 |
|------|------|
| `IPC_STAT` | 공유 메모리 객체 정보를 얻어옴 (`struct shmid_ds *buf`에 객체 복사) |
| `IPC_SET` | **r/w 권한, euid, egid** 변경 |
| `IPC_RMID` | 공유 메모리 **삭제** |

---

## 2. 정보 조회 — IPC_STAT

```c
struct shmid_ds shmds;
shmctl(shmid, IPC_STAT, &shmds);
```
`IPC_STAT` 명령으로 얻은 공유 메모리 객체는 `buf` 인자에 저장된다.

---

## 3. 권한 변경 — IPC_SET

기존 공유 메모리 객체의 `shm_perm.uid`, `shm_perm.gid`, `shm_perm.mode` 값을 변경한다.
이 세 값이 변경되면 `shmid_ds`의 `shm_ctime`이 변경 시각으로 갱신된다.

```c
struct shmid_ds shmds;                  // 공유 메모리 객체 선언

shmctl(shmid, IPC_STAT, &shmds);        // 현재 객체 얻어옴

shmds.shm_perm.uid  = changeuid;        // uid 변경
shmds.shm_perm.gid  = changegid;        // gid 변경
shmds.shm_perm.mode = changemode;       // 접근 모드 변경

shmctl(shmid, IPC_SET, &shmds);         // 변경 내용 적용
```

> 패턴: `IPC_STAT`로 현재 객체를 읽어와 일부 필드만 수정한 뒤 `IPC_SET`으로 반영.

---

## 4. 삭제 — IPC_RMID

```c
shmctl(shmid, IPC_RMID, 0);
```

- 삭제를 요청해도 **다른 프로세스가 아직 사용 중(첨부되어 있음)이면 즉시 삭제되지 않음**
- 모든 프로세스로부터 **분리(detach)되어 `shm_nattach` 값이 0이 될 때까지** 기다린 후 삭제

> 메시지 큐의 `IPC_RMID`(즉시 삭제)와 달리, 공유 메모리는 **첨부 카운트가 0이 되어야** 실제 삭제된다.

---

## 정리

- 제어 함수는 `shmctl(shmid, cmd, buf)`
- `IPC_STAT` = 객체 정보 조회(buf로 복사)
- `IPC_SET` = uid/gid/mode 변경 (변경 시 `shm_ctime` 갱신), STAT→수정→SET 패턴
- `IPC_RMID` = 삭제 요청. 단, `shm_nattach == 0`이 될 때까지 대기 후 삭제
