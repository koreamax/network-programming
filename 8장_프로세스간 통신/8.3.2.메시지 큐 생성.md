# 8.3 메시지 큐 (Message Queue) — 8.3.2 메시지 큐 생성

## 1. `msgget()` — 메시지 큐 생성

```c
int msgget(key_t key, int msgflg);
```

| 인자 | 설명 |
|------|------|
| `key` | 메시지 큐를 구분하기 위한 **고유 키** |
| `msgflg` | 메시지 큐 생성 시 **옵션**을 지정 |

- 메시지 큐가 생성되면 `int` 형식의 **메시지 큐 ID**가 반환됨
- 임의의 프로세스는 이 **메시지 큐 ID**를 통해 메시지 큐를 이용

### 메시지 큐 객체
메시지 큐가 새로 만들어질 때마다 메시지 큐 객체(`struct msgid_ds`)가 생성된다.
다음 정보가 저장된다.
- 마지막으로 메시지를 송신/수신한 프로세스의 PID
- 메시지 송수신 시각
- 큐의 최대 바이트 수
- 메시지 큐 소유자 정보 등

## 2. 메시지 큐 객체 정의

```c
struct msgid_ds {
    struct ipc_perm   msg_perm;     // 메시지 큐의 접근 권한
    struct msg       *msg_first;    // 메시지 큐의 처음 메시지
    struct msg       *msg_last;     // 메시지 큐의 마지막 메시지
    time_t            msg_stime;    // 마지막으로 메시지가 송신된 시각
    time_t            msg_rtime;    // 마지막으로 메시지가 수신된 시각
    time_t            msg_ctime;    // 마지막으로 change가 수행된 시각
    struct wait_queue *wwait;
    struct wait_queue *rwait;
    ushort            msg_cbytes;
    ushort            msg_qnum;
    ushort            msg_qbytes;   // 메시지 큐의 최대 바이트 수
    ushort            msg_lspid;    // 마지막으로 msgsnd를 수행한 PID
    ushort            msg_lrpid;    // 마지막으로 받은 PID
};

struct ipc_perm {
    key_t   key;
    ushort  uid;     // owner의 euid
    ushort  gid;     // owner의 egid
    ushort  cuid;    // 생성자의 euid
    ushort  cgid;    // 생성자의 egid
    ushort  mode;    // 접근 모드의 하위 9 bits
    ushort  seq;     // 순서번호(sequence number)
};
```

## 3. `msgflg` 인자

- 메시지 큐 생성 시 **옵션**을 지정
- **비트마스크(bitmask)** 형태로, `IPC_CREAT`, `IPC_EXCL` 등의 상수와
  유닉스의 **파일 접근 권한**을 함께 지정 가능

### IPC_CREAT
커널 안에 메시지 큐가 존재하는지 확인한 후 큐를 생성한다.

```c
int mode = 0660;
int msgflag = IPC_CREAT | mode;
int msgid = msgget(key, msgflag);
```

### IPC_EXCL
`IPC_CREAT`와 함께 사용될 때, 큐가 **이미 존재하면 실패(-1)** 처리한다.

```c
int mode = 0660;
int msgflag = IPC_CREAT | IPC_EXCL | mode;
int msgid = msgget(key, msgflag);
```

### IPC_PRIVATE
`key` 값으로 `IPC_PRIVATE`를 사용하면:
- **키가 없는** 메시지 큐 객체 생성
- 부모-자식 프로세스처럼 **명시적으로 키 값을 정의할 필요가 없는 경우**에 사용
- 외부의 다른 프로세스는 이 메시지 큐에 **접근할 수 없음**

## 4. `mkq.c` — 메시지 큐 생성 예제

- `msgget()`을 이용하여 메시지 큐를 생성하는 프로그램
- 키 값을 명령 인자로 받아 메시지 큐 객체를 생성한 후 **메시지 큐 ID 출력**
- `msgflg` 인자에 `0`을 넣으면 **기존에 생성된** 메시지 큐 객체의 ID를 얻어옴

---

## 정리

- 생성/조회 함수는 `msgget(key, msgflg)`, 반환값은 **메시지 큐 ID**
- 큐마다 객체 `struct msgid_ds` 생성 (권한, 송수신 PID/시각, 최대 바이트 수 등)
- `msgflg`는 비트마스크: `IPC_CREAT`(없으면 생성), `IPC_EXCL`(있으면 실패), 권한 OR 조합
- `IPC_PRIVATE` key → 외부 접근 불가, 키 정의 불필요한 경우(부모-자식 등)에 사용
- `msgflg = 0` → 기존 메시지 큐의 ID 조회
