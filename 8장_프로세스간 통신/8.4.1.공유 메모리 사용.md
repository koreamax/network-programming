# 8.4 공유 메모리 (Shared Memory) — 8.4.1 공유 메모리 사용

## 1. 개요

- 여러 프로세스가 **공통으로 사용할 수 있는 메모리 영역**
- 데이터를 한 번 읽어도 메모리에 계속 남아 있어,
  **동일한 데이터를 여러 프로세스가 중복하여 읽어야 할 때** 효과적

### 관련 함수
| 함수 | 역할 |
|------|------|
| `shmget()` | 공유 메모리 **생성** |
| `shmat()` | 생성된 공유 메모리를 자신의 **가상 메모리 주소에 첨부(attach)** |
| `shmdt()` | 공유 메모리를 자신의 메모리 영역에서 **분리(detach)** |
| `shmctl()` | 공유 메모리 정보 조회 / 삭제 등 **제어** |

---

## 2. `shmget()` — 공유 메모리 생성

```c
int shmget(key_t key, int size, int shmflg);
```

| 인자 | 설명 |
|------|------|
| `key` | 공유 메모리를 식별하기 위한 값. 다른 프로세스가 접근하려면 이 키 값을 알아야 함. `IPC_PRIVATE` 사용 시 키 없는 객체 생성 |
| `size` | 공유 메모리 크기 |
| `shmflg` | 생성 옵션 (비트마스크) |

### shmflg
- `IPC_CREAT`, `IPC_EXCL` 등의 상수와 유닉스 **파일 접근 권한**을 비트마스크로 함께 지정

```c
int mode = 0660;
int shmflg = IPC_CREAT | mode;
int shmid = shmget(key, size, shmflg);
```

| 상황 | 결과 |
|------|------|
| 같은 `key`의 공유 메모리가 **이미 존재** | 그 객체의 **ID 반환** |
| 존재하지 않음 | 새 객체 **생성 후 ID 반환** |
| `IPC_CREAT \| IPC_EXCL` 인데 같은 key가 **이미 존재** | **실패, -1 반환** |

## 3. 공유 메모리 객체 — `struct shmid_ds`

```c
struct shmid_ds {
    struct ipc_perm shm_perm;     // 동작 허가사항
    int             shm_segsz;    // 세그먼트의 크기 (bytes)
    time_t          shm_atime;    // 마지막 attach 시각
    time_t          shm_dtime;    // 마지막 detach 시각
    time_t          shm_ctime;    // 마지막 change 시각
    unsigned short  shm_cpid;     // 생성자의 PID
    unsigned short  shm_lpid;     // 마지막 접근자의 PID
    short           shm_nattach;  // 현재 attach 수

    // private
    unsigned short  shm_npages;   // 세그먼트의 크기 (pages)
    unsigned long  *shm_pages;    // array of ptrs to frames
    struct vm_area_struct *attaches; // descriptors for attaches
};
```

## 4. `shmat()` — 첨부 (attach)

공유 메모리를 실제로 사용하려면, 물리적 주소를 자신의 프로세스 **가상 메모리 주소로 매핑**해야 한다. 이 매핑을 **첨부(attach)** 라고 한다.

```c
void *shmat(int shmid, const void *shmaddr, int shmflg);
// 성공 시 첨부된 주소 반환, 에러 시 (void *) -1
```

| 인자 | 설명 |
|------|------|
| `shmid` | 공유 메모리 객체 ID |
| `shmaddr` | 첨부시킬 주소. **`0`을 넣으면 커널이 빈 공간을 자동으로 찾아 처리** |
| `shmflg` | `0`으로 지정하면 공유 메모리에 **읽기·쓰기 모두 가능** |

### 사용 예
```c
int shmid = shmget(0x1234, 1024, IPC_CREAT | 0660);
char *myaddr = shmat(shmid, 0, 0);

// shmat은 에러 시 (char *) -1 반환
if (myaddr == (char *) -1) {
    perror("공유메모리를 attach하지 못했습니다\n");
    exit(0);
}
```

---

## 5. `shmdt()` — 분리 (detach)

공유 메모리 사용이 끝나면 자신의 메모리 영역에서 **분리(detach)** 한다.

```c
int shmdt(const void *shmaddr);
// shmaddr: shmat()가 반환했던 주소 (현재 프로세스에 첨부된 공유 메모리의 시작 주소)
```

- 분리되었다고 해서 **공유 메모리가 삭제되는 것은 아님**
- 단지 **현재 프로세스만** 해당 공유 메모리를 사용할 수 없게 됨

---

## 정리

- 공유 메모리는 여러 프로세스가 같은 데이터를 중복 접근할 때 효율적
- 흐름: `shmget`(생성) → `shmat`(첨부) → 사용 → `shmdt`(분리) → `shmctl`(제어/삭제)
- `shmget`: 같은 key 존재 시 ID 반환, `IPC_EXCL` 조합이면 이미 존재할 때 실패(-1)
- `shmat`: `shmaddr=0`이면 커널이 주소 자동 할당, `shmflg=0`이면 읽기·쓰기 가능, 에러 시 `(void *) -1`
- `shmdt`는 첨부 해제일 뿐 삭제가 아님 (삭제는 `shmctl`의 `IPC_RMID`)
