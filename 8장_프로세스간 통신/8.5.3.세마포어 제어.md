# 8.5 세마포어 (Semaphore) — 8.5.3 세마포어 제어

## 1. `semctl()` — 세마포어 제어

세마포어 사용 종료, 값 읽기/설정, 특정 멤버를 기다리는 프로세스 수 확인 등의 제어 함수.

```c
int semctl(int semid, int member_index, int cmd, union semun semarg);
```

| 인자 | 설명 |
|------|------|
| `semid` | 제어할 대상의 세마포어 ID |
| `member_index` | 세마포어 멤버 번호 |
| `cmd` | 수행할 동작 |
| `semarg` | `cmd` 종류에 따라 다르게 사용되는 공용체 |

### `union semun`
```c
union semun {
    int                 val;     // SETVAL을 위한 값
    struct semid_ds    *buf;     // IPC_STAT, IPC_SET을 위한 버퍼
    unsigned short int *array;   // GETALL, SETALL을 위한 배열
    struct seminfo     *_buf;    // IPC_INFO를 위한 버퍼
    void               *_pad;    // dummy
};
```

---

## 2. 제어 명령 (cmd)

### 정보 조회 / 객체

#### IPC_STAT — 세마포어 객체 얻어오기
`semid_ds` 타입의 세마포어 객체를 얻어온다. (`member_index`는 **사용 안 함**)
```c
struct semid_ds semobj;
union semun semarg;
semarg.buf = &semobj;
semctl(semid, 0, IPC_STAT, semarg);   // semarg.buf로 객체 접근
```

---

### 값 설정 (초기화)

#### SETVAL — 특정 멤버 값 설정
세마포어 생성 후 공유 데이터 수를 설정(초기화)하는 명령. `semarg.val`에 초기값 지정.
```c
union semun semarg;
unsigned short semvalue = 10;
semarg.val = semvalue;
semctl(semid, 2, SETVAL, semarg);     // 2번 멤버 세마포어 값을 10으로 설정
```

#### SETALL — 집합 내 모든 멤버 값 초기화
`semarg.array`에 초기값 배열을 넣어준다. (`member_index`는 **사용 안 함**)
```c
unsigned short values[] = {3, 14, 1, 25};   // 멤버 수 = 4
union semun semarg;
semarg.array = values;
semctl(semid, 0, SETALL, semarg);
```

---

### 값 읽기

#### GETVAL — 특정 멤버의 현재 값
```c
int n = semctl(semid, 2, GETVAL, 0);   // 2번 멤버 세마포어 값
```

#### GETALL — 모든 멤버의 현재 값
```c
union semun semarg;
unsigned short semvalues[3];            // 멤버 수 = 3
semarg.array = semvalues;
semctl(semid, 0, GETALL, semarg);

for (i = 0; i < 3; i++)
    printf("%d 번 멤버 세마포어의 값 = %d\n", i, semvalues[i]);
```

---

### 대기/소유 정보

#### GETNCNT — 대기 중인 프로세스 수
특정 멤버 세마포어를 사용하기 위해 **블록되어 있는 프로세스의 수**
(= 세마포어 값이 원하는 값 이상으로 증가되기를 기다리는 프로세스 수)를 반환.
```c
semctl(semid, member_index, GETNCNT, 0);
```

#### GETPID — 마지막 semop() 수행 프로세스의 PID
특정 멤버에 대해 마지막으로 `semop()`을 수행한 프로세스의 PID를 반환. (`semarg` 미사용)
```c
int pid = semctl(semid, member_index, GETPID, 0);
```

---

### 삭제

#### IPC_RMID — 세마포어 삭제
```c
semctl(semid, 0, IPC_RMID, 0);
```

---

## 3. 명령 요약

| cmd | 동작 | member_index | semarg |
|-----|------|:---:|:---:|
| `IPC_STAT` | 세마포어 객체 조회 | 미사용 | `.buf` |
| `SETVAL` | 특정 멤버 값 설정(초기화) | 사용 | `.val` |
| `SETALL` | 모든 멤버 값 초기화 | 미사용 | `.array` |
| `GETVAL` | 특정 멤버 현재 값 | 사용 | 미사용 |
| `GETALL` | 모든 멤버 현재 값 | 미사용 | `.array` |
| `GETNCNT` | 대기 중인 프로세스 수 | 사용 | 미사용 |
| `GETPID` | 마지막 semop 수행 PID | 사용 | 미사용 |
| `IPC_RMID` | 세마포어 삭제 | 미사용 | 미사용 |

---

## 정리

- 제어 함수는 `semctl(semid, member_index, cmd, semarg)`
- 초기화: `SETVAL`(한 멤버, `.val`) / `SETALL`(전체, `.array`)
- 값 읽기: `GETVAL`(한 멤버) / `GETALL`(전체, `.array`)
- 상태: `GETNCNT`(대기 프로세스 수), `GETPID`(마지막 semop PID)
- 조회: `IPC_STAT`(`.buf`), 삭제: `IPC_RMID`
- `member_index`가 의미 있는 명령(SETVAL/GETVAL/GETNCNT/GETPID)과 무시되는 명령(STAT/SETALL/GETALL/RMID) 구분
