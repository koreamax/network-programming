# 3.1.2 프로세스 메모리 배치

## 📌 개요

프로세스가 실행되려면 일정한 메모리가 필요하며, **할당받은 메모리 영역을 프로세스 이미지(process image)** 라 한다.

---

## 🗺 프로그램의 가상 메모리 구조

<img width="841" height="349" alt="process_memory_layout" src="https://github.com/user-attachments/assets/e09b86bb-375f-4144-8186-af63c452d52d" />

가상 메모리는 **kernel space**와 **user space**로 나뉘며, user space는 다시 여러 영역으로 세분화된다.

| 영역 | 위치 | 저장 내용 |
|------|------|-----------|
| **kernel** | 3GB ~ 4GB (kernel space) | 운영체제 커널 |
| **stack** | 3GB 아래 (위에서 아래로 증가) | **지역 변수** |
| **heap** | (아래에서 위로 증가) | 동적 할당 메모리 |
| **bss** | data 위 | **초기화되지 않은 전역 변수** |
| **data** | text 위 | **초기화된 전역 변수** |
| **text** | 0번지부터 | **명령어** (프로그램 코드) |

> 💡 stack은 위에서 아래로, heap은 아래에서 위로 자란다. 두 영역이 가운데에서 만나면 메모리 부족으로 에러가 발생한다.

## 🔬 프로세스 이미지 — 예제 코드

```c
#include <stdio.h>
#include <stdlib.h>

extern char **environ;          // extern 변수

int init_global_var = 3;        // 초기화된 global 변수 (초기값 3)
int unint_global_var;           // 초기화되지 않은 global 변수

int main(int argc, char **argv)
{
    int auto_var;               // 자동 변수
    static int static_var;      // static 변수
    register int reg_var;       // register 변수
    char *auto_ptr;             // 자동 변수

    auto_ptr = malloc(10);      // 메모리를 10 바이트 할당

    return 0;
}
```

### 변수별 메모리 영역 매핑

| 메모리 영역 | 세부 영역 | 저장되는 변수 / 내용 |
|-------------|-----------|----------------------|
| **환경변수와 명령행 인자 영역** | — | `*environ` 내용 |
| **스택 (stack)** | — | `argc`, `argv`, `auto_var`, `reg_var`, `auto_ptr` |
| **힙 (heap)** | — | `malloc()`이 할당한 10 바이트 |
| **데이터 영역** | 초기화 안 된 데이터 영역 (bss) | `unint_global_var`, `static_var` |
| | 초기화 된 데이터 영역 (data) | `init_global_var = 3` |
| **코드 영역 (text)** | — | 어셈블된 프로그램 코드 |

> 💡 `static_var`는 함수 내부에 선언되어도 **bss 영역**에 저장된다. (지역 변수처럼 보이지만 수명은 프로그램 전체)

## 📚 스택과 힙

### 정의

| 영역 | 정의 | 수명 |
|------|------|------|
| **스택 (stack)** | 현재 호출되어 실행중인 **함수의 코드와 환경 정보**를 저장하는 영역 | 함수 종료 시 **자동으로 사라짐** |
| **힙 (heap)** | 함수가 리턴되어도 **메모리가 사라지지 않는** 영역 | `free()` 호출 시까지 유지 |

### 예제: 스택과 힙의 차이

```c
int main() {
    char *ptr;
    ptr = func();

    free(ptr);              // 힙 영역 사용 종료
}

char *func() {
    // char arr[10];        // arr은 스택 영역에 할당된다
    char *arr;
    arr = malloc(10);       // arr은 힙 영역에 할당된다
    return arr;
}
```

### 두 가지 방식 비교

| 선언 방식 | 저장 위치 | 함수 종료 후 |
|-----------|-----------|--------------|
| `char arr[10];` | **스택** | 메모리 **사라짐** → `func()` 외부에서 사용 불가 |
| `arr = malloc(10);` | **힙** | 메모리 **유지됨** → `func()` 외부에서도 접근 가능 |

> ⚠️ **메모리 누수 주의**: 힙에 할당한 메모리는 사용이 끝난 뒤 반드시 `free()`로 해제해야 한다. 그렇지 않으면 프로그램이 종료될 때까지 메모리가 점유된다.

> 💡 **반대 함정**: 스택 변수의 주소를 함수 밖으로 리턴하면 **dangling pointer**가 된다. 함수가 끝나는 순간 그 메모리는 무효화되기 때문이다.

---

## ✅ 핵심 요약

1. 프로세스에 할당된 메모리 영역을 **프로세스 이미지**라고 한다.
2. 가상 메모리는 **kernel space**와 **user space**(stack / heap / bss / data / text)로 구성된다.
3. **초기화된 전역 변수는 data**, **초기화되지 않은 전역 변수와 static 변수는 bss** 영역에 저장된다.
4. **스택**은 함수 호출 시 생성되어 종료 시 사라지며, **힙**은 `free()` 전까지 유지된다.
5. **`malloc()`은 힙**, 일반 지역 변수는 스택에 할당되며, 두 영역의 차이를 이해해야 메모리 누수와 dangling pointer를 막을 수 있다.
