# 3.1.3 프로세스 생성과 종료

## 📌 개요

컴퓨터에서는 여러 프로세스가 OS의 관리하에 동시에 실행되며, 각 프로세스는 자신만의 이미지를 메모리에 갖는다.

<img width="892" height="590" alt="computer_processes_memory" src="https://github.com/user-attachments/assets/77f4754a-1b25-4892-b1a9-782b92066589" />


- 컴퓨터 내부에서는 여러 프로세스(`프로세스 1` ~ `프로세스 N`)가 **OS의 중재**로 CPU를 공유하며 실행된다.
- 메모리에는 각 프로세스의 이미지가 **독립적으로** 적재되어 있다.

---

## 🍴 `fork()` — 프로세스 복제

### 개념

- 임의의 프로세스가 자신과 같은 기능을 수행하는 프로세스를 **복제**할 수 있는 함수.
- `fork()`를 호출한 프로세스를 **parent process**, 새로 생긴 프로세스를 **child process** 라고 한다.

### 프로세스간에 공유되는 자원

- **공유되는 것**: parent process의 **코드**, **스택**, **파일 기술자**, **소켓 번호**
- **공유되지 않는 것**: **변수**

> 📝 정확히는 `fork()` 직후 자식은 부모의 메모리(스택/힙/데이터)를 **복사본**으로 갖는다. 두 프로세스가 변수를 따로 가지므로 한쪽이 수정해도 다른 쪽에 영향을 주지 않는다.

### PID로 구별

- 프로세스는 각자의 **PID (Process Identification)** 로 구별된다.

- 새 이미지는 프로세스 5의 이미지를 **복사**한 것

## 🔢 `fork()` 함수의 리턴 값

```c
#include <unistd.h>

pid_t fork(void);
// Returns: 0 in child,
//          process ID of child in parent,
//          -1 on error
```

### 부모와 자식이 보는 리턴 값이 다르다

<img width="642" height="385" alt="fork_return_value" src="https://github.com/user-attachments/assets/55f14375-bcc3-4ab0-ae6e-268585311d9f" />


| 호출 전 | 호출 후 | 리턴 값 |
|---------|---------|---------|
| parent process (PID = 1999) | parent process (PID = 1999) | **2000** (자식의 PID) |
| | child process (PID = 2000) | **0** |

> 💡 동일한 코드가 실행되더라도 리턴 값으로 부모/자식을 구분할 수 있다.

```c
pid_t pid = fork();
if (pid == 0) {
    // 자식 프로세스가 실행할 코드
} else if (pid > 0) {
    // 부모 프로세스가 실행할 코드 (pid는 자식의 PID)
} else {
    // fork 실패
}
```

## 🌐 `fork()`와 클라이언트/서버 상태

서버에서 `fork()`로 자식 프로세스를 만들어 클라이언트를 처리하는 패턴.

### `fork()` 직후 상태

<img width="824" height="277" alt="fork_client_server_after" src="https://github.com/user-attachments/assets/563c9469-2512-4114-b95c-3401b862f441" />

- **server (parent)** — `listenfd`, `connfd` 모두 보유
- **server (child)** — fork로 인해 `listenfd`, `connfd`를 **모두 복사**받음
- **client** — `connect()`로 서버와 연결됨

### 부모와 자식이 적절한 소켓을 close 한 후 상태

<img width="874" height="282" alt="fork_client_server_close" src="https://github.com/user-attachments/assets/8055c471-7f82-4727-8c0c-72e494a30e8c" />


| 프로세스 | 닫는 소켓 | 유지하는 소켓 |
|----------|-----------|---------------|
| **server (parent)** | `connfd` 닫음 | `listenfd` 유지 → 새 클라이언트 대기 |
| **server (child)** | `listenfd` 닫음 | `connfd` 유지 → 클라이언트와 통신 |

> 💡 이렇게 분담함으로써 부모는 새 연결을 계속 받고, 자식은 기존 클라이언트를 전담 처리한다 (concurrent server 패턴).

## 🔄 `exec` 함수 — 프로세스 이미지 교체

### 개념

- 프로세스가 하던 작업을 종료하고 **다른 작업을 하도록 전환**할 때 사용.
- `exec` 함수를 호출하면 현재 실행 중이던 **프로세스 이미지를 새로운 이미지로 교체**한다.

### `exec` 함수군

```c
#include <unistd.h>

int execl (const char *path, const char *arg, ...);
int execv (const char *path, char *const argv[]);
int execle(const char *path, const char *arg, ..., char *const envp[]);
int execve(const char *path, char *const argv[], char *const envp[]);
int execlp(const char *file, const char *arg, ...);
int execvp(const char *file, char *const argv[]);
```

### 함수 이름의 접미사 의미

| 접미사 | 의미 |
|:---:|------|
| `l` | **list** 형태의 인자를 취한다는 의미 |
| `v` | **vector** 형태의 인자를 취한다는 의미 |
| `p` | 명령을 **PATH에서 검색**하겠다는 의미 |
| `e` | **환경변수** 인자를 받는 함수임을 의미 |

### 함수 비교 표

| 함수 | 인자 형식 | PATH 검색 | 환경변수 |
|------|:---:|:---:|:---:|
| `execl` | list | ❌ | ❌ |
| `execv` | vector | ❌ | ❌ |
| `execlp` | list | ✅ | ❌ |
| `execvp` | vector | ✅ | ❌ |
| `execle` | list | ❌ | ✅ |
| `execve` | vector | ❌ | ✅ |

> 💡 일반적으로 `fork() → exec()` 패턴으로 사용한다. 자식 프로세스를 만들고 그 안에서 다른 프로그램을 실행하는 방식.

---

## 🌱 프로세스의 환경변수

### 개념

- 모든 프로세스는 실행을 위해 필요한 **환경변수**를 가진다.
- `fork()`를 실행하면 **부모 프로세스의 환경변수 영역이 자식 프로세스에게 복사**된다.

### 환경변수 조회 함수

```c
char *getenv(const char *name);
```

특정 환경변수의 값을 알아낼 때 사용 (예: `getenv("PATH")`).

### 모든 환경변수 출력

외부 전역변수 `char **environ`을 사용한다.

```c
extern char **environ;

for (i = 0; environ[i] != NULL; i++)
    printf("%s\n", environ[i]);
```

> 💡 `environ`은 환경변수 문자열의 포인터 배열이며, 마지막은 `NULL`로 끝난다.

## 🛑 프로세스의 종료

### 종료 조건 (3가지)

1. **`main()` 함수에서 return**되는 경우
2. **`exit()`가 호출**되는 경우
3. **프로세스를 종료시키라는 시그널(signal)** 을 다른 프로세스나 운영체제로부터 수신한 경우

### `exit()` 함수

- 프로세스가 **자신을 종료**시키는 데 사용
- 열려 있던 **모든 파일을 닫기 위하여 자동으로 `close()`를 호출**

> 🛡 `exit()`는 프로세스 정리를 자동으로 해주므로, 명시적으로 자원을 해제하지 않아도 비교적 안전하게 종료된다.

---

## ✅ 핵심 요약

1. **`fork()`** 는 프로세스를 복제하며, 부모와 자식은 **PID로 구별**된다 (코드/스택/소켓은 공유, 변수는 복사본).
2. `fork()`의 리턴 값은 **자식에게는 0**, **부모에게는 자식의 PID**이다.
3. 서버가 `fork()`한 후 부모는 `connfd`, 자식은 `listenfd`를 닫아 역할을 분담한다.
4. **`exec` 함수**는 현재 프로세스 이미지를 새로운 이미지로 교체하며, 접미사(`l/v/p/e`)에 따라 인자 형식이 다르다.
5. 프로세스 종료는 **`return` / `exit()` / 시그널 수신** 3가지 방법으로 일어나며, `exit()`는 열린 파일을 자동으로 닫는다.
